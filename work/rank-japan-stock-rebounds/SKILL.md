# 日本株の復活候補を順位付けする

現在の下落率そのものではなく、悪材料が改善する経路と、急落前後の値動きから回復確度を判定する。順位は期待上昇率ではなく、急落前の直近価格帯へ戻る確率を優先する。

## 分析条件を固定する

- 明示がなければ対象を日本株の当日下落率上位20銘柄とする。
- 短期を数日から1カ月、中期を1カ月から6カ月とする。
- 「復活」を前日終値または急落前の直近レンジの回復と定義する。年初来高値への回帰を暗黙の目標にしない。
- 取引時間中は取得時刻を表示し、暫定評価と明記する。大引け後は終値で再取得する。
- 「今日」「現在」は必ず絶対日付と日本時間へ解決する。

## データを集める

1. `市場データ収集` の利用可能データを確認し、下落率ランキングを取得する。利用できる場合は `225225jp` の `japan_ranking`、`kind=losers`、`limit=20` を優先する。スキーマエラー時はデータ一覧を再確認する。
2. 各銘柄について現在値、騰落率、順位、取引所、配信時刻を保存する。
3. `ニュース取得ツール` で当日と直近数日の市場要因、個別材料を検索する。検索対象設定を確認し、銘柄名、証券コード、決算、下方修正、上方修正、希薄化などを組み合わせる。
4. 会社の決算短信、決算説明資料、適時開示を一次資料として確認する。一次資料で足りない市場予想や地合いはロイターなどで補う。
5. 過去の株価を最低20営業日、可能なら52週まで確認する。直前5～10営業日の上昇率、急落後の位置、52週高安、出来高、株式分割調整の有無を確認する。
6. 決算発表や重要開示が当日後刻に予定されている銘柄は「判定保留」とし、発表前の本順位から外す。

市場データ用ツールが使えない場合は、信頼できるリアルタイム市場サイトをウェブ検索して代替する。ニュース用ツールに記事がない場合も、公式IRと信頼できる報道へ検索を広げる。時点の異なる価格を混在させない。

## 悪材料を分類する

各銘柄で、下落理由を一つの短い因果関係にまとめる。推測と確認済み事実を分ける。

- **一時的・測定可能**: 売上計上の期ずれ、一過性障害、検収遅延など。回収時期と確認指標があるなら高評価にする。
- **期待値調整**: 好決算でも上方修正がない、直前急騰後の材料出尽くし、業種全体の売り。業績が維持され、過熱が解消したなら回復候補にする。
- **循環的**: 半導体、電子部品などの需要循環。受注、在庫、稼働率、顧客投資計画に改善指標がある場合だけ評価する。
- **構造的**: 恒常的な競争力低下、継続赤字、財務悪化、会計・統治問題、大幅希薄化。具体的な是正策と期限がなければ復活候補から外す。

悪材料が改善しそうという物語だけでは足りない。期限、金額、受注残、利益率、認証・検収、資金調達完了など、次の決算までに観測できる指標を最低一つ要求する。

## 過去の値動きで補正する

- 急落前5～10営業日で15～25%以上上昇していた場合、当日の下落をそのまま割安化とみなさない。現在値が上昇前より高ければ短期評価を下げる。
- 好業績を保ったまま急落前の起点や52週安値付近へ戻った場合、短期回復評価を上げる。
- 過去の同種決算や業種ショック後の戻り方が確認できる場合、回復日数と最大下落率を比較する。
- 株式分割前後、上場直後、1円刻みの低位株、出来高の乏しい銘柄は単純比較しない。

詳細な採点と減点条件は [references/scoring.md](references/scoring.md) を読む。

## 順位を決める

1. 改善経路が確認できない銘柄を本順位から外す。
2. 残った銘柄を改善可視性、業績、値動き、財務・評価、触媒で採点する。
3. 短期と中期を別々にA～Dで評価する。
4. 同点なら、一時的要因が数値で確認でき、直近上昇を十分に解消し、財務余力がある銘柄を上位にする。
5. 高い上昇余地より、高い回復確度を優先する。

## 回答を組み立てる

冒頭で上位3銘柄と、短期・中期それぞれの最有力を示す。続いて、以下の列を持つ順位表を出す。

| 列 | 内容 |
|---|---|
| 復活順位 | 回復確度順 |
| 銘柄・現在値 | コード、下落率、市場順位、取得時刻 |
| 短期／中期 | A～D |
| 悪材料と改善経路 | 原因、改善期限、観測指標 |
| 過去値動き | 直前上昇、急落後の位置、比較対象 |
| 判断が崩れる条件 | 次の決算・開示で確認する否定条件 |

表の後に次を短く添える。

- 条件付き候補: 改善経路はあるが、まだ確認できない銘柄
- 見送り: 構造悪化、希薄化、財務不安、材料未確認などで除外した銘柄
- 市場文脈: 全面安か、特定業種だけの売りか
- 再判定の契機: 大引け、決算時刻、次回決算、検収・受注発表など

価格・決算数値・ニュースには直接リンクを付ける。事実と推論を混ぜず、「～と推定」「～の色が濃い」と明示する。一般的な注意書きより、銘柄ごとの無効化条件を優先する。

## 品質確認

- ランキング全体を確認せず、知名度の高い銘柄だけを選んでいないか。
- 当日下落率と、直前数日の上昇分の吐き出しを区別したか。
- 悪材料の改善を測る数値・期限があるか。
- 一次資料と価格の時点が一致しているか。
- 発表前の決算を既知として扱っていないか。
- 年初来高値を「復活」の当然の目標にしていないか。
- 上昇余地ではなく回復確度で並べたか。
