# データ取得と判定の契約

## 使用する情報源

| 情報源 | 主用途 | 重要な制約 |
|---|---|---|
| KabusController `kabus_ranking` | 取引中のプライム値下がり速報、現在値、騰落率 | 対象日がなく、出来高・売買代金の単位確認が必要 |
| J-Quants `equities_master` | プライム普通株判定、正式社名、業種 | 日次。実データの対象日を確認する |
| J-Quants `equities_bars_daily` | 引け後ランキング、調整済みOHLCV、売買代金、時価総額 | 日次。場中現在値として使わない |
| J-Quants `fins_summary` | 最新実績、会社予想、EPS、CF、財務、開示時刻 | 四半期実績と通期予想を同じ期間として比較しない |
| J-Quants `fins_earnings_date` | 決算予定日 | 変更履歴を含むため最新公表分へ絞る |
| J-Quants `markets_calendar` | 前営業日、時間切れ日の計算 | プライム現物は`HolDiv=1`または`2`を営業日とする |
| 225225.jp | 対象日照合、指数・33業種の地合い | 個別銘柄の確定母集団に使わない |
| 会社公式IR、TDnet・JPX適時開示 | 会社固有の急落原因、改善策、期限、KPI | 深掘り候補だけ原文を確認する |
| ニュース取得ツール | Reutersの市場反応、JPXマーケットニュース、JPX株式売買停止情報 | 会社IR・TDnetの網羅経路ではない |

EDINET DB、政策DB、J-Quantsの`edinet_*`は使わない。yfinanceとinvestpyもこの分析には使わない。

## プライム普通株の条件

J-Quants V2の銘柄マスターで次をすべて満たす銘柄だけを対象にする。

- `Mkt=0111`
- `ProdCat=011`
- 5桁の`Code`の末尾が`0`
- `CoName`に「優先株式」を含まない

`ProdCat=011`だけでは優先株が混ざる。列名を推測せず、英字を含む表示コードもJ-Quantsの5桁コードを銘柄マスターから取得する。

## 下落率母集団

### 取引中

`kabus_ranking(ranking_type="2", exchange_division="TP")`の返却全件をJ-Quants銘柄マスターと突合する。プライム普通株の条件を適用した後、ランキング番号順の先頭20銘柄を速報母集団にする。普通株判定前に20件へ切らない。

- 対象取引日をJ-Quantsの最新日足または225225.jpで照合する。
- 価格時刻に日付がない場合、照合した対象日と取得時刻を別々に記録する。
- ランキングの出来高・売買代金は単位が確定するまで計算へ使わない。
- 出力まで5分を超えた場合はランキングを再取得する。

### 取引日の大引け後

J-Quantsの当日分が更新済みなら、対象日と前営業日の全銘柄日足を取得し、プライム普通株だけ次式で再計算する。

```text
騰落率 = 当日AdjC / 前営業日AdjC - 1
```

両日の`AdjC`が非nullで、当日の`Vo`が正の銘柄に限定する。引け後にJ-Quantsの対象日が当日へ更新されていなければ、J-Quants取引カレンダーで当日が営業日であり、225225.jp等のランキング対象日も当日と一致する場合だけ、KabusControllerのランキングを「引け後速報」として使う。対象日を照合できなければ当日ランキングと呼ばず、前営業日のJ-Quantsランキングへも置き換えない。

### 取引開始前・休場日

当日のランキングはまだ形成されていない。J-Quantsから最新公式取引日とその前営業日を取得してランキングを再計算し、対象日を明記する。休場日のKabusControllerランキングを当日値と呼ばない。

## 価格履歴

母集団20銘柄には、直前20日売買代金中央値と過熱を判定できるよう、現在値の直前までの調整済み日足を21本取得する。深掘り候補は期間を広げる。

- 母集団は21本、深掘り候補は通常60営業日
- 支持抵抗や中期比較に必要な場合は最大120営業日
- 調整済み`AdjO`、`AdjH`、`AdjL`、`AdjC`、`AdjVo`
- 実出来高`Vo`、売買代金`Va`
- `AdjFactor`、`ExRT`、ストップ高・安を示す`UL`・`LL`フラグ

`AdjFactor`の変化、権利落ち、分割・併合が急落日に重なる場合は、調整の整合を確認できない限り候補外にする。nullを0へ変換しない。

20日売買代金中央値は`Va`を使い、通常1億円以上を売買案の条件とする。時価総額は単位を検証できる場合だけ補助に使い、固定の時価総額ゲートを設けない。

当日出来高・売買代金倍率はJ-Quants当日分が更新済みの場合だけ計算する。取引中は単位未確認のKabu値から倍率を作らず、未算定を減点しない。

225225.jpの`japan_industries`が現在値`value`とポイント差`change`だけを返す場合、業種騰落率は次式で計算する。

```text
業種騰落率 = change / (value - change)
```

ポイント差を個別株の騰落率と直接比較しない。`updated_date`と`updated_time`を照合してから相対下落に使う。

## 業績と決算

`fins_summary`では、最新業績と会社予想を最新の該当開示行から確認する。

- 開示日・時刻、文書種別、対象期間
- 売上高、営業利益または業種に適した利益、純利益、EPS
- 通期会社予想と予想変更
- 配当、発行済株式・自己株式の確認可能な項目

営業CF、現金、自己資本等が最新行で空なら、過去へ遡って最新の非空行を対象期間・開示日付きで使う。予想変更は、同一会計年度の前回予想との比較または会社の修正開示で確認し、単一行だけから推定しない。

Q1～Q3実績は累計、会社予想は通期である。進捗率を市場予想との差や上振れ確率と呼ばない。赤字企業へPERを強制せず、業種に適した評価指標が確認できる場合だけ評価へ使う。

決算予定は`fins_earnings_date`を優先する。`Code + FYE + FQName`ごとに`PubDate`が最新の行だけを残し、`SchDate`が空または分析日以前の行を除いたうえで、最も近い将来日を次回決算日とする。最新行の`SchDate`が空なら古い予定へ戻さない。3月期・9月期だけを収録するカレンダーを全社網羅とみなさない。発表時刻が不明なら日付だけを確定情報として扱い、次回日程が未公表であることだけで候補外にしない。

## 急落原因の確認

### 会社固有の急落

次の順で原因を確認する。

1. 会社公式IRまたはTDnet・JPX適時開示の原文
2. J-Quants財務サマリーの数値と開示時刻
3. Reuters等の発信元が明確な報道

公式原文まで確認できればA評価を許容する。信頼できる報道だけで原因を確認した場合はBを上限とする。根拠が推論だけなら最終候補にしない。

増資・新株予約権では、会社原文の最大発行株数と、発表前の発行済株式数から自己株式を除いた分母を使う。

```text
最大潜在希薄化率 = 最大新規発行株数 / (発表前発行済株式数 - 自己株式数)
```

発行条件または株数が未確定なら推定せず、条件確定まで見送る。

### 地合い・業種要因

会社固有の開示がないことだけで失格にしない。TOPIX、33業種、同業銘柄の同時下落と、最新会社予想が維持されていることを確認し、相対下落が説明できる場合は評価する。

ニュース記事が0件でも「材料なし」と断定しない。正式社名、法人格を除いた名称、表示コードを分けて検索し、会社IRも確認する。

## 必須と任意を分ける

最終候補に必要なのは次の3組だけとする。

1. プライム普通株判定、価格日時、下落率、調整済み日足21本以上の価格・出来高
2. 会社固有、地合い、業種、需給のいずれかに分類できる急落原因
3. 最新決算・会社予想の主要数値

いずれかが欠ける銘柄は候補外にし、次順位を調べる。分析全体を止めない。

次回決算日は公表済みなら必ず確認する。未公表の日程、信用残、空売り、現在板、詳細セグメント、同業倍率、52週履歴は任意とする。取得できた場合だけ加点・警告に使い、欠損を中立的な悪材料として扱わない。

## 時刻と鮮度

次を混同しない。

| 時刻 | 意味 |
|---|---|
| 分析時刻 | 回答を作成したJST日時 |
| 取得時刻 | ツールが情報を取得した日時 |
| 価格時刻・日足`Date` | 価格が成立した日時・取引日 |
| `DiscDate`・`DiscTime` | 財務情報の開示日時 |
| ニュース`published_at` | 記事の公開日時 |
| 信用・空売り基準日 | 遅行需給データの対象日 |

場中価格、日足、財務、ニュースの時点を混在させず、順位や売買案を左右する時点差だけを回答へ簡潔に示す。

## 状態変更を避ける

通常経路で使うKabu系データは`kabus_ranking`に限定する。現行データ一覧で上流の登録状態を変える可能性が示される`arbitrary_board_snapshot`、`kabus_regulations`、`kabus_symbol_info`、`kabus_primary_exchange`、`kabus_margin_premium`は使わない。

銘柄登録、登録解除、注文、取消、口座・建玉操作を行わない。情報取得に必要な外部サイトへの閲覧は、会社IR、TDnet・JPX、信頼できる報道に限定する。
