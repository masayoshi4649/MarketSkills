## 1. 復活根拠指数 0～100

確率ではなく、最終ランキングの並び順を決める尺度である。各項目をmin/base/maxで評価する。

| 項目 | 点 | 高得点条件 |
|---|---:|---|
| ショックの一時性・修復可能性 | 25 | 原因、改善策、期限、観測KPIを一次資料で確認できる |
| 業績耐久性・会社予想 | 20 | 需要、利益率、CF、受注が計画を支える |
| 財務余力・資本政策・統治 | 15 | 財務健全、希薄化懸念なし、統治問題なし |
| 期限付き触媒・KPI | 15 | 時間軸内に独立して観測可能な確認機会がある |
| 自社過去・同業比の評価余地 | 10 | 同一期EPS等で再計算した倍率に無理がない |
| 過熱解消・価格出来高リセット | 10 | 急落前上昇を解消し、支持帯・出来高で価格発見中 |
| 市場・業種に対する超過下落説明 | 5 | 相対下落のうち会社固有と地合いを説明できる |

原因不明は採点保留とする。重要項目欠損時は総合点を「算定不能」とし、欠損を中立点や推測幅で埋めない。部分点は採点済み項目と配点分母を併記し、100点満点へ外挿しない。幅が重なる銘柄は同一tierとする。

## 2. 売買成立指数 0～100

| 項目 | 点 | 高得点条件 |
|---|---:|---|
| 価格発見・反転確認 | 30 | 安値更新停止、レンジ回復、確認高値上抜け |
| 最初の目標までのR/R | 25 | 最初の抵抗まで1.5R以上、2R候補あり |
| 流動性・スリッページ | 20 | 売買代金、板、呼値が想定売買に十分 |
| 決算・開示ギャップリスク | 15 | 近い重要イベントがなく、材料確認済み |
| 信用・空売り混雑 | 10 | 週次・報告データ上の極端な混雑がない |

必要入力を満たして算定した結果が60未満なら監視扱いにし、具体的入口を提示しない。支持抵抗、現在板、流動性、イベント日程などの重要入力が欠ける場合は「算定不能・監視」とする。復活根拠指数で代用しない。

## 3. 短期復活スコア 0～100

最大20営業日の復活を別評価する。復活根拠指数や売買成立指数と合算しない。

| 短期項目 | 点 | 高得点条件 |
|---|---:|---|
| 反転・支持形成 | 25 | 安値更新停止、レンジ回復、出来高の吸収を確認 |
| R/R・流動性 | 20 | 最初の抵抗まで1.5R以上あり、板と売買代金が十分 |
| ショックの短期可逆性 | 20 | 一過性または過度な期待調整と一次情報で判定 |
| 20営業日内の触媒・ギャップリスク | 20 | 確認日が明確で、未解決の重要イベントがない |
| 需給・過熱解消・相対下落 | 15 | 直前急騰を十分に解消し、市場・業種比の行き過ぎが説明可能 |

急落原因の一次確認、鮮度条件を満たす現在値・板、調整済み20営業日以上のOHLC・出来高・売買代金、ATR20・支持抵抗・R/R、20営業日内の決算・開示日程のいずれかが欠ければ算定不能とする。

## 4. 中期復活スコア 0～100

最大60営業日の復活を別評価する。

| 中期項目 | 点 | 高得点条件 |
|---|---:|---|
| 業績・需要の耐久性 | 25 | 会社予想、受注、継続収益、利益率、CFが計画を支える |
| 修復経路・観測KPI | 25 | 改善策、数値KPI、確認期限が一次資料で明確 |
| 財務余力・資本政策・統治 | 20 | 回復までの資金余力があり、希薄化・統治懸念がない |
| 評価余地・目標帯の妥当性 | 15 | 同一期EPS等の適切な指標で目標帯を再計算できる |
| 60営業日内の触媒・需給回復 | 15 | 決算、検収、受注、生産、自社株等の独立した確認機会がある |

急落原因と修復可能性の一次確認、最新の会社予想・業績・CF・財務余力、原因に対応するKPIと期限、業種に適した同一期の評価入力と60営業日内のイベント日程のいずれかが欠ければ算定不能とする。

## 5. S/A/B/C変換と上限条件

| 格付け | スコア | 解釈 |
|---|---:|---|
| S | 85～100 | 時間軸内の復活根拠が複数独立し、確認時期も明確 |
| A | 75～84 | 復活根拠は強いが、1つ以上の条件依存が残る |
| B | 60～74 | 復活経路はあるが、追加確認が必要 |
| C | 0～59 | 現時点の復活根拠または売買条件が弱い |

格付けは将来確率を表さない。スコアと格付けを`A（78/100）`のように併記する。必須入力が欠ける場合はCに丸めず「算定不能」とする。短期・中期のどちらかが算定不能な銘柄は最終ランキングに入れない。

**短期Sの上限条件**

- 復活根拠指数70以上、売買成立指数75以上とする。
- 原因を一次情報で確認し、根拠確信度を高とする。
- 現在値・板が鮮度条件を満たし、最初の抵抗まで1.5R以上ある。
- 5営業日以内に未解決の決算・重要開示がない。

一つでも満たさなければ短期格付けはAを上限とする。売買成立指数が60未満なら短期格付けはCを上限とし、入口案を禁止する。

**中期Sの上限条件**

- 復活根拠指数80以上とする。
- 原因、修復KPI、確認期限を一次情報で確認し、根拠確信度を高とする。
- 業績、CF、財務余力が回復期間を支える。
- 未解決の希薄化、会計、統治問題がない。

一つでも満たさなければ中期格付けはAを上限とする。外部需要循環だけに依存し、会社固有の観測KPIがなければBを上限とする。

復活順位は復活根拠指数で決める。格付けは時間軸別の説明に使い、順位を置き換えず、複数スコアを合算しない。

## 6. 選別ファネルと深掘り優先度

| 段階 | 対象 | 取得範囲 | 停止・次ステップ |
|---|---|---|---|
| F0 母集団 | rawランキング | 市場データの一括結果 | 普通株・日付・nullゲートへ |
| F1 安価ゲート | F0通過全件 | 銘柄マスター、価格、流動性、時価総額、JPX共通一覧 | ハード除外・観測・保留を即時分類 |
| F2 原因見出し | F1通過候補 | ニュース・JPXイベントの一括または見出し、既取得資料 | 早期除外・保留を判定 |
| F3 優先順位 | F2通過候補 | 安価な項目だけで優先度を算定 | 上位8、例外最大10へ絞る |
| F4 限定深掘り | F3選択候補 | 一次開示、詳細財務、履歴、板、需給 | 取得ごとに停止規則を再評価 |
| F5 最終順位 | 両格付け算定可能候補 | 4スコア、入口・出口に必要な範囲 | 必要入力欠損は保留へ |

F3の深掘り優先度は0～10とし、投資品質の点数として表示しない。

| 優先度項目 | 点 |
|---|---:|
| 日付付きの原因候補があり、一次確認が容易 | 0～3 |
| 標準レーンで売買代金に余裕 | 0～2 |
| 相対下落が大きく、直前過熱の残存が小さい | 0～2 |
| 60営業日内の測定可能な触媒候補 | 0～2 |
| 市場データの鮮度と欠損の少なさ | 0～1 |

8位で同点の場合は、直前20日売買代金中央値、次にデータ鮮度で決める。10銘柄を超えて同点候補を深掘りしない。

## 7. 早期除外と取得停止

早期除外は企業価値の断定ではなく、この実行で深掘り枠を使わない判定である。次のいずれかで停止する。

1. ハード除外の単一条件を信頼できる情報で確認した。
2. 観測レーンの単一条件を確認し、ユーザーが低流動性等を明示的に対象としていない。
3. 決定的な早期除外材料E01～E04を1つ確認した。
4. 補助的な早期除外材料E05～E09を、異なるデータ区分から2つ確認した。

| コード | 区分 | 早期除外材料 |
|---|---|---|
| E01 | 決定的 | 需要または競争力の構造悪化を会社が示し、期限付き改善策・KPIがない |
| E02 | 決定的 | 需要減を主因とする通期下方修正と、受注・売上・利益率の悪化が一次情報で同時に確認できる |
| E03 | 決定的 | 急落事象の回復期限が60営業日を明確に超え、それ以前の独立触媒がない |
| E04 | 決定的 | 急落前価格帯の前提となる会社予想・事業・資本構成が失われた |
| E05 | 補助的 | 需要減を伴う下方修正または赤字拡大 |
| E06 | 補助的 | 営業CF悪化、ネット有利子負債増、または資金繰り余力低下 |
| E07 | 補助的 | 受注、継続率、稼働率、利益率等の原因対応KPIが悪化 |
| E08 | 補助的 | 急落後も急騰前起点を15%以上上回り、最初の有意な抵抗まで1.5R未満 |
| E09 | 補助的 | 60営業日内の測定可能な改善機会を既取得情報で確認できない |

E09だけで除外しない。E05～E08のいずれかと組み合わせる。同じ記事の転載や同じ財務数値は2根拠に数えない。

停止後は、その銘柄のEDINET詳細、詳細財務、セグメント、IR文書、個別ニュース追加検索、政策DBを呼ばない。除外を確定するための一次資料1件が未確認な場合だけ、最小限の確認を許可する。既知の悪材料を政策テーマで救済しない。

銘柄ごとに、到達段階、最終状態、理由コード、停止根拠1行、最終取得種別を保持する。回答では理由コード別件数を全件分示し、簡潔ログは代表例を最大10件示す。合計はファネル件数と一致させる。

## 8. ハード除外

| コード | 条件 |
|---|---|
| H01 | 非普通株、上場廃止、売買停止 |
| H02 | 継続企業の重大な疑義、債務超過 |
| H03 | 未解決の重大な会計・内部統制問題 |
| H04 | MBO・TOB等で価格が制度的に固定 |
| H05 | 構造悪化に改善KPIがない |
| H06 | 最大潜在希薄化率20%以上 |

H06の資本救済等の例外は別枠で説明し、通常ランキングに混ぜない。

## 9. 観測レーン

| コード | 条件 |
|---|---|
| O01 | 株価100円未満 |
| O02 | 直前20日売買代金中央値1億円未満 |
| O03 | 時価総額50億円未満 |
| O04 | IPO後60営業日未満または日足20営業日未満 |
| O05 | 値幅下限または一方向板 |

閾値を満たさないことと企業価値が低いことを同一視しない。個別深掘りと具体的な円価格売買案を既定で停止し、再評価条件だけを示す。

## 10. 保留

| コード | 条件 |
|---|---|
| P01 | 同日後刻の決算・重要開示 |
| P02 | 安価な見出し・JPX確認で原因候補を特定できず、深掘り優先順位外 |
| P03 | 重要資料がデータベースへ未反映 |
| P04 | 分割調整、EPS、発行株数の不整合 |
| P05 | 発行価格や株数が未確定の増資 |
| P06 | 主要価格が二源で0.5%以上不一致 |
| P07 | 優先度Aの一次確認を実行できず、順位・格付け・出口の確定に影響する |
| P08 | 短期または中期格付けの必須入力が欠損 |

希薄化率10～20%は大幅減点し、10%未満も資金用途、1株価値、需給を確認する。下方修正、需要減、営業CF悪化、受注減は大きく減点する。自動イベント重要度が低くても原本を優先する。

## 11. 外部DBの利用優先度

取得前に「結果が除外、順位、短期・中期格付け、出口のいずれかを変え得るか」を問う。次の優先度を事前に付ける。

| 優先度 | 条件 | 例 | 取扱い |
|---|---|---|---|
| A 高 | 最終候補の核心を一次確認し、結果が順位・格付け・出口を変える | 急落原因、重大開示、希薄化、会社予想、決算日 | 最初に取得。EDINET一次確認を政策DBより優先 |
| B 条件付き | 安価な選別後も候補が拮抗し、追加確認で候補間順位が変わり得る | 追加KPI、セグメント、資金用途、直接性の高い政策 | 安価な代替情報で解決しない場合だけ取得 |
| C 低 | 結論に必要ない背景補足、早期除外後、総当たり | 除外済み銘柄の詳細、全候補の網羅財務、政策テーマ総当たり | 取得しない |

EDINETはバッチ取得を優先し、同一パラメータの結果を実行中に再利用する。政策DBは最終候補の投資仮説の中核で、直近・重要・会社事業に直接の政策を照合するときだけ使う。政策テーマ所属だけで使わない。

取得後も早期除外を再評価し、成立した銘柄の後続取得を停止する。回答には、利用したDB、目的、優先度、バッチ・再利用、省略したCと、省略が順位・格付け・出口に与える影響を示す。Aを省略した場合は推測で補わずP07とする。

## 12. 根拠確信度

- 高: 原因・数値・期限が一次情報で整合し、主要欠損なし。
- 中: 原因は確認済みだが、外部需要や実行力への依存が残る。
- 低: AI抽出、報道、古いデータへの依存がある。原則順位外または監視。

walk-forwardで校正するまでは「復活確率72%」のような確率表示を禁止する。実装後は過去時点で利用可能だったデータだけを使い、目標到達、ストップ、時間切れ、平均R、最大不利変動を検証する。
