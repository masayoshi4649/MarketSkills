# 入口・出口・時間管理

## 1. 指標

調整済み日足で計算する。

```text
TR = max(高値-安値, abs(高値-前日終値), abs(安値-前日終値))
ATR20 = 直近20営業日のTR平均
出来高倍率 = 当日出来高 / 直前20営業日出来高中央値
売買代金倍率 = 当日売買代金 / 直前20営業日売買代金中央値
```

支持・抵抗は複数回反応、出来高集中、窓、急落前レンジから求める。ATRだけで目標を作らない。呼値未確認の価格は「概算帯」と表示する。

## 2. 反転型の入口

1. 急落日の安値更新が止まる。
2. 確認日終値が急落日レンジ中点を回復する。
3. 確認日高値の上抜けをトリガーとする。
4. エントリー帯を`トリガー～トリガー+0.25ATR20`とする。
5. `+0.5ATR20`超の上窓では追わない。

取引中の急落日は原則として終値確認待ちにする。分足・VWAPを取得できない場合、架空の場中反転を作らない。

## 3. 押し目型の入口

支持帯を再テストして安値を割らず、出来高が縮小した後の確認日高値上抜けを要求する。急落理由の解釈未完、最初の有意な抵抗まで1.5R未満、予定損失が1.5ATRまたは10%超なら入口なしとする。

## 4. ストップと利確

想定約定帯中心を`E`、ストップ候補を`S`、`1R=E-S`とする。

- `S`: 構造支持または急落安値の下へ0.25～0.5ATRの余白を置く。
- 利確1: 1R以上にある最初の抵抗帯で3分の1を売る。
- 利確2: 急落前レンジ下限、窓の中点、または2R付近で3分の1を売る。
- 残り: 急落前終値・レンジ上限を上限候補とし、1ATRまたは直近2営業日安値で追随する。
- 利確1後: 新材料がなければストップを建値付近へ引き上げる。

現在値からの上昇率と想定約定値からの上昇率を別々に示す。ストップ価格での約定を保証せず、下方ギャップリスクを記す。

## 5. ファンダメンタル無効化

銘柄ごとに、価格ストップとは別に次を具体化する。

- 通期下方修正または赤字転落
- 新規希薄化、想定を上回る発行株数
- 受注、受注残、継続率、検収、利益率等のKPI未達
- 会計・統治問題の発覚
- 改善期限の延期または撤回

## 6. 時間切れ

- 市場・需給ショック: 10営業日
- 決算期待値調整: 20営業日
- 一時要因の回収: 会社が示す期限、上限60営業日
- 5営業日で+0.5R未達: 縮小を検討
- 期限日に前提を確認できない: 撤退

取引カレンダーを使い絶対日付で表示する。

## 7. 決算跨ぎ

新規建て予定から5営業日以内に決算がある場合は原則見送る。保有中は前営業日引けで閉じるか半減を既定とする。決算自体を検証イベントとする場合だけ通常の半分以下の別枠とし、上振れ・下振れギャップを明記する。
