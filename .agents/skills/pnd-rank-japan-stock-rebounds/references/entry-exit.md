# 条件付き入口と出口

売買案は、買い候補、条件付き買い候補、復活確度点65以上の反転待ちを対象に最大3銘柄まで作る。条件付き買い候補は将来の発動条件、反転待ちは数値化またはイベント通過の待機条件として示す。場中板を必須にせず、確定した調整済み日足から再現可能な条件を作る。

## 計算

```text
TR = max(高値-安値, abs(高値-前日終値), abs(安値-前日終値))
ATR20 = 直近20営業日のTR平均
出来高倍率 = 当日出来高 / 直前20営業日出来高中央値
売買代金倍率 = 当日売買代金 / 直前20営業日売買代金中央値
```

出来高・売買代金倍率はJ-Quantsの当日分が更新済みの場合だけ使う。支持・抵抗は、複数回反応した価格、出来高集中、窓、急落前レンジから求める。ATRだけで目標価格を作らない。

取引中のKabuランキングには当日高値・安値がない。急落日OHLCが未確定なら、当日レンジを推測せず「大引け後に急落日OHLCを取得して数値化」と記載し、円価格の入口・損切りは出さない。前営業日までの支持帯とATRは参考条件に限る。

急落日OHLC確定後、反転確認前の仮R/Rは次で計算する。

```text
仮エントリーE0 = min(急落日高値, 急落日レンジ中点 + 0.25ATR20)
仮ストップS0 = 急落日安値 - 0.25ATR20
仮1R = E0 - S0
仮R/R = (最初の有意な抵抗 - E0) / 仮1R
```

仮R/Rが1.5以上で、5営業日以内に公表済み重要イベントがなければ「条件付き買い候補」にできる。確認日高値が確定したら実際の想定約定帯中心でR/Rを再計算し、1.5未満なら発動せず見送る。

## 入口

### 反転型

1. 急落日の安値更新が止まる。
2. 確認日の終値が急落日レンジの中点を回復する。
3. 確認日高値の上抜けを入口トリガーにする。
4. 想定約定帯はトリガーから`+0.25ATR20`までとする。
5. `+0.5ATR20`を超えて上窓を開けた場合は追わず、押し目を待つ。

取引中の急落日は「反転待ち」とする。大引け後に急落日OHLCが確定し、復活確度点と仮R/Rの条件を満たせば「条件付き買い候補」とし、確認日終値と高値を使った将来の入口、損切り、利確候補を示す。取引中は「急落日レンジ中点を終値で回復し、その確認日高値を翌営業日以降に上抜け」という非数値条件と再評価時刻だけを示す。

### 押し目型

急落後に形成した支持帯を再テストし、支持を終値で割らず、出来高が縮小した後の確認日高値上抜けを入口にする。

最初の有意な抵抗まで1.5R未満、ストップまで1.5ATRまたは10%超、公表済みの決算が5営業日以内の場合は新規買いを見送る。

## 損切り

想定約定帯の中心を`E`、ストップを`S`、`1R=E-S`とする。

- 構造的な支持帯または急落安値の下へ`0.25～0.5ATR20`の余白を置く。
- 呼値を確認できない場合は概算帯と明記し、実在しない細かい価格を作らない。
- 終値で前提が崩れた場合の撤退を基本とするが、重大開示では翌日ギャップが生じ得ることを一文で示す。

## 利確

- 第1利確: 1.5R以上にある最初の有意な抵抗帯で3分の1
- 第2利確: 急落前レンジ下限、窓の中点、または2R付近で3分の1
- 残り: 1ATRまたは直近2営業日安値で追随
- 第1利確後: 新しい悪材料がなければストップを建値付近へ引き上げる

急落前価格帯の前提が壊れた場合は、価格目標を機械的に維持しない。

## 時間切れ

### 短期

- 5営業日で`+0.5R`へ届かなければ縮小を検討する。
- 10～20営業日で反発が成立しなければ撤退する。
- 決算や重要KPIの直前に未達なら、イベント前に閉じる。

### 中期

- 次回決算または原因に対応するKPIの確認日を検証期限にする。
- 改善を確認できないまま6カ月を超えて保有しない。
- 会社が示した期限が6カ月より早い場合は、その期限を優先する。

営業日は取引カレンダーで計算し、時間切れを絶対日付で示す。

## 前提が崩れる条件

価格ストップとは別に、銘柄ごとに該当するものを具体化する。

- 通期下方修正、赤字転落、需要減の拡大
- 受注、受注残、稼働率、利益率、検収等の原因対応KPI未達
- 新規希薄化または想定を上回る発行株数
- 会計・統治問題
- 改善期限の延期または撤回

急落日OHLCが確定済みの場合、入口、損切り、第1・第2利確、時間切れ日、前提が崩れる条件を一つの表にまとめる。取引中で未確定なら、円価格欄を「大引け後算定」とし、反転条件と再評価時刻を示す。
