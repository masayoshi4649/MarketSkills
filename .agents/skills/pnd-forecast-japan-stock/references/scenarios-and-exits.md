## 1. 現在値基準

評価基準価格を`P0`とし、JST日時と価格種別を固定する。

```text
現在値からの騰落率 = (シナリオ価格 / P0 - 1) × 100
予想PER             = P0 / 同じ評価年度のEPS
シナリオ価格        = シナリオEPS × シナリオPER
```

前日終値との比較は当日の値動き説明に限り、将来レンジの主比較にしない。

## 2. シナリオの作り方

弱気・基本・強気ごとに、利益前提と評価倍率前提を分離する。

- 弱気: 会社計画未達、利益率低下、需要・受注鈍化、倍率収縮を反映する。
- 基本: 会社計画の達成可能性と現在の業種倍率を中心に置く。
- 強気: 達成条件が観測可能な上振れだけを織り込む。根拠のない最高倍率を使わない。

評価倍率は同一期の自社履歴、比較可能な同業中央値・分位、または出所と基準日が明確な市場予想から選ぶ。これらが未取得なら12倍・15倍・18倍等の任意の整数を仮置きせず、`シナリオEPS × 未確定倍率`の感応度式または「算定不能」と表示する。

短期1・5営業日は支持抵抗、ATR、イベント反応を重くし、20・60営業日はEPS、利益率、受注、評価倍率を重くする。各価格帯は単一手法で断定せず、次の交差で決める。

1. EPS×倍率の感応度
2. 支持・抵抗、窓、急落前レンジ
3. ATRから見た通常変動域
4. 開示・決算の観測期限

## 3. 値動きの尺度

調整済み日足で真の値幅とATR20を計算する。

```text
TR = max(高値-安値, abs(高値-前日終値), abs(安値-前日終値))
ATR20 = 直近20営業日のTR平均
出来高倍率 = 当日出来高 / 直前20営業日出来高中央値
```

支持・抵抗は実際の複数回反応、出来高集中、急落前レンジ、窓から求める。ATRだけで目標を作らない。分足やVWAPを取得できない場合、架空の場中反転条件を置かない。

## 4. 新規入口

急落日の成行逆張りを既定にしない。標準の反転型は次とする。

1. 急落安値の更新が止まる。
2. 確認日の終値が急落日レンジ中点を回復する。
3. 確認日高値の上抜けをトリガーとする。
4. 入口帯を`トリガー～トリガー+0.25ATR20`とする。
5. `+0.5ATR20`を超えて上窓を開けた場合は追わない。

押し目型は、支持帯再テスト後に安値を割らず、出来高縮小後の確認日高値上抜けを要求する。公式材料が未確認、最初の抵抗帯まで1.5R未満、予定損失幅が1.5ATRまたは10%超なら新規案を出さない。

## 5. 出口

想定約定帯中心を`E`、ストップ候補を`S`、`1R = E - S`とする。呼値が確認できれば有効呼値へ丸め、未確認なら「概算帯」と表示する。

- 損切り: 構造支持または急落安値の外側へ0.25～0.5ATRの余白を置く。材料無効化を併記する。
- 第1利確: 1R以上にある最初の抵抗帯。標準で3分の1を売る。
- 第2利確: 急落前レンジ下限、窓の中点、または2R付近。標準で3分の1を売る。
- 残り: 1ATRまたは直近2営業日安値で追随する。

第1利確後は新材料がなければストップを建値付近へ引き上げる。下方ギャップ時はストップ価格で約定できる保証がない。

既存保有者には、取得単価に依存しない「事業前提を維持できる保有条件」と、取得単価を受け取った場合の損益別案を分けて示す。含み損を理由に急落前価格を必達目標にしない。

## 6. 決算と時間切れ

- 新規建てから5営業日以内に決算がある場合は原則見送る。
- 保有中は前営業日引けで閉じるか半減を既定とする。
- 決算を検証イベントとする場合だけ、通常の半分以下の別枠としギャップリスクを示す。
- 5営業日で+0.5R未達なら縮小を検討する。
- 市場・需給ショックは10営業日、決算期待値調整は20営業日、一時要因回収は会社が示す期限を基準にする。
- 時間切れ日は取引カレンダーで絶対日付へ変換する。

## 7. 確信度

確信度は高・中・低とし、確率に見せない。

- 高: 現在価格、一次開示、EPS、発行株数、主要KPIが整合し、原因と期限が確認済み。
- 中: 主要数値は整合するが、外部需要または市場倍率への依存が残る。
- 低: 原因、現在板、EPS、触媒のいずれかが未確認。価格帯は監視用に限定する。

重要データ欠損、シナリオ間の前提重複、二源不一致がある場合は確信度を一段以上下げる。
