# 社会経済学

## 1. 本スキルでの目的と適用条件

社会的相互作用、規範、ネットワーク、格差、社会移動が、消費、労働供給、政策選好、企業収益へ伝わる経路を整理する。日経225・TOPIX・NT分析では、次のいずれかを満たす場合だけ方向ドリフトの候補にする。

- 公式統計または事前予定のある政策発表に、予想との差を測れる更新がある。
- 企業開示や構成銘柄データから、対象テーマへの売上・費用・人員エクスポージャーを確認できる。
- 社会的な変化が為替、金利、消費、賃金、財政または実際の資金フローへ接続したことを別データで確認できる。

格差、信頼、人口構成、社会関係資本の水準は通常は遅い状態変数である。単独で当日またはD1～D5の上げ下げを決めず、イベントの背景、シナリオ条件または中長期レジームとして扱う。SNS投稿量や検索量だけを「社会心理」や売買需給の代理にしない。

## 2. 体系的な基礎概念

| 概念 | 要点 | 観測候補 |
|---|---|---|
| 社会的相互作用 | 他者の行動や属性が個人の効用・制約を変える | 参照集団、同僚・地域・世帯の構成 |
| 内生効果 | 集団平均の行動が個人行動へ作用する | 同時決定のため識別が難しい |
| 外生・文脈効果 | 集団の観測属性が個人行動へ作用する | 年齢、所得、教育、産業構成 |
| 相関効果 | 共通環境や自己選択が似た行動を生む | 地域固定効果、選別、共通ショック |
| 社会関係資本 | 信頼、規範、つながりが協調や情報移転を支える | 橋渡し型、結束型、参加、ネットワーク構造 |
| 規範・アイデンティティ | 所属カテゴリーと期待行動が選好・努力・対立を変える | 調査回答、制度、職場・家庭内役割 |
| 格差・社会移動 | 所得・資産分布と世代間順位の持続性 | ジニ係数、分位比、順位相関 |
| 集団力学 | 小さな個別選好が集計上の分離や転換点を生む | 閾値、クラスター、複数均衡 |

社会関係資本は一つの量ではない。結束の強さ、異なる階層間の接続、参加率を分離し、異なる定義の系列を混ぜない。

## 3. 主要モデル・式・仮定

### 3.1 加重ジニ係数

所得 `y_i`、標本重み `w_i > 0`、`W = Σ_i w_i`、加重平均 `μ = Σ_i w_i y_i / W` に対して、

`G = Σ_i Σ_j w_i w_j |y_i - y_j| / (2 μ W²)`

とする。現行の`economic_toolkit`に合わせて`y_i ≥ 0`かつ`μ > 0`、同じ所得概念・価格基準・世帯等価尺度を仮定する。負所得を含む分布へこの実装を使わない。税引前と可処分所得、個人と世帯、名目と実質を混ぜない。

### 3.2 線形平均相互作用

`y_i = α + β x_i + γ x̄_{g,-i} + δ ȳ_{g,-i} + u_i`

- `δ`：内生的な同調または波及
- `γ`：集団属性による文脈効果
- `u_i`：個人・集団の未観測要因

同時点の`y_i`と`ȳ_g`だけでは、内生効果、文脈効果、相関効果を分離できない「反射問題」がある。外生的な集団割当、ネットワーク構造、時間差、実験・準実験などの識別が必要である。

### 3.3 離散選択と社会的相互作用

二値行動の平均を`m`、私的利得を`a_i`、相互作用強度を`J`、誤差尺度を`σ`とすると、

`m = E[Λ((a_i + Jm) / σ)]`

という固定点で表せる。`Λ`はロジスティック分布関数である。`J`が大きいと複数均衡や転換点が生じ得るため、平均的な係数だけで局所ショック後の均衡を一意に選べない。

### 3.4 ネットワーク上の意見更新

`z_{t+1} = W z_t`

`W`は非負で各行の和が1の重み行列とする。強連結性や非周期性などの条件下で合意へ収束し得る。ただし、これは意見集約の機構であり、合意値の正しさや価格予測力を保証しない。

### 3.5 社会的増幅

識別済みの単純な線形モデルで`|δ| < 1`なら、外生ショックの総増幅を`1 / (1 - δ)`と書ける。これは構造係数と参照集団が安定している場合だけ使う。推定されていない`δ`を仮置きして市場インパクトを膨らませない。

## 4. 日経225・TOPIX・NT分析への条件付き接続

1. 公式系列について、同一定義の市場予想`c_k`と公表値`x_k`、過去の公表誤差標準偏差`σ_k`から`s_k = (x_k-c_k)/σ_k`を作る。予想がない場合はサプライズと呼ばない。
2. テーマ`k`に対する指数`I`の構成銘柄エクスポージャー`e_{I,k}`を、日経225は価格加重、TOPIXは浮動株時価総額加重で別計算する。
3. 期限一致で推定した感応度`β_k`がある場合だけ、相対寄与候補を`ΔNT_social = Σ_k (e_{N225,k}-e_{TOPIX,k}) β_k s_k`と置く。
4. `β_k`の符号と大きさはローリングまたはウォークフォワードで推定し、固定方向則にしない。金利、為替、業種リターン、同時発表を統制する。
5. 実際の先物・ETFフロー、板、建玉は需給へ、社会統計から収益・政策への経路はファンダメンタルズへ置く。同一事象を両方へ重複加点しない。

消費者態度の悪化は、消費鈍化、金融緩和期待、財政支援期待を同時に生み得る。格差拡大も再分配期待、社会不安、貯蓄率、業種別需要を異なる方向へ動かし得る。したがって、指数方向はイベント、政策反応、金利・為替、市場の織込みを条件に決める。

## 5. 反証・限界

- 集団平均の相関を個人への因果効果とみなしていないか。
- 参照集団、ネットワーク、所得定義、調査設計の変更を時系列変化と誤認していないか。
- 低頻度の格差・社会関係資本をD1～D5の直接シグナルにしていないか。
- SNS利用者の選択、ボット、アルゴリズム変更、同じニュースの反復を除けているか。
- 複数均衡モデルで、観測されていない均衡選択を断定していないか。
- 社会指標と景気・資産価格の逆因果、共通ショックを除けているか。
- 日本以外で識別された効果量を、日本の制度・指数構成へ無調整で移植していないか。
- 指数の加重方式と構成銘柄エクスポージャーを実日時点で再計算したか。

反証条件は、符号反転する公式サプライズ、政策反応の不発、想定した金利・為替経路の不成立、構成銘柄の実測感応度消失、期限一致検証の失敗として事前に置く。

## 6. 現行economic_toolkitの計算名

| 計算名 | 最小入力 | 返り値 |
|---|---|---|
| `gini_coefficient` | 非負値、任意の正規化可能な重み | ジニ係数、加重平均、観測数 |

社会的増幅、固定点、ネットワーク合意、指数感応度は、構造推定や複数解の扱いを要するため現行の純計算器へ含めない。別に推定する場合も、未実装名を`economic_toolkit`の計算名として記載しない。
