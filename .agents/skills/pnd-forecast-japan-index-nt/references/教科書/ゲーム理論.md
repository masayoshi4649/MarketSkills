# ゲーム理論

## 1. 本スキルでの目的と適用条件

ゲーム理論は、政策当局、企業、情報保有者、マーケットメーカー、裁定者が互いの反応を見越す状況を条件付きシナリオへ分解するために使う。プレイヤー、行動集合、情報、順序、利得、均衡概念を具体化できない場合は比喩としても方向点へ使わない。

- 適用する: 中央銀行・政府の反応関数、企業の価格・生産競争、情報非対称な板、政策交渉、指数リバランスへの先回り。
- 適用しない: 「市場対当局」のように主体や利得が曖昧な説明、均衡を未来の唯一経路とみなす説明。

## 2. 体系的な基礎概念

- 戦略形ゲーム: プレイヤー、戦略、利得の組で表す。
- 最適反応とNash均衡: 他者戦略を所与とした一方的逸脱の利得改善がない組。
- 混合戦略: 行動の確率分布。観測頻度を直ちに意図的混合とみなさない。
- 展開形・部分ゲーム完全性: 行動順序、観測、信頼できない脅しを分ける。
- 不完備情報・Bayesゲーム: 自然が型を選び、各主体が情報集合に応じて信念を更新する。
- シグナリング・スクリーニング: 行動が私的情報を伝える条件と、分離・一括均衡を扱う。
- 反復ゲーム・協調: 将来利得、監視、逸脱検出が協調可能性を左右する。
- 相関均衡: 共通信号に条件づけた推奨から逸脱する誘因がない分布。

## 3. 主要モデル・式・仮定

```text
Nash均衡 s*:
ui(si*, s-i*) >= ui(si, s-i*)  for every i and si

Bayes最適反応:
si*(ti) ∈ argmax_si E[u_i(si, s-i(T-i), ti, T-i) | ti]

Bayes更新:
P(t | a) = P(a | t)P(t) / Σt' P(a | t')P(t')

反復ゲームの単純協調条件例:
短期逸脱利得 <= 将来協調利得の割引現在価値
```

均衡の存在、一意性、選択、学習、共通知識は別問題である。利得を価格変化だけで代理すると、規制目的、在庫、顧客フロー、評判等を落とし得る。

## 4. 日経225・TOPIX・NT分析への条件付き接続

| 場面 | ゲームの定義 | 分析への接続 |
|---|---|---|
| 金融政策 | 当局の型、物価・景気損失、声明・政策手段、市場の信念 | 公式反応関数と指標サプライズでシナリオを作り、予定イベント前は分散を優先する |
| 企業競争 | 価格・数量・設備行動、費用、代替性、先手後手 | 業種利益率と指数ウェイトへ集計し、寡占だから強気とはしない |
| 板と情報 | 情報保有者、ノイズ注文、競争的マーケットメーカー | adverse-selection成分をスプレッドと価格発見へ接続し、方向とは分ける |
| 政策・地政学 | 排他的行動、期限、利得、情報、交渉順序 | 検証可能なシナリオ重みと条件付き日本株分布を別原典にする |
| リバランス・ロール | 公知ルール、予想フロー、先回り、執行期限 | 価格影響と巻き戻しを別窓にし、同一イベントの二重加点を避ける |

Polymarket等の価格はシナリオ重みの参考であり、ゲームの利得や `P(日経/TOPIX方向 | シナリオ)` を与えない。

## 5. 反証・限界

- プレイヤー、情報集合、利得、行動順序の一つでも観測不能なら複数モデルを併記する。
- 複数均衡では恣意的な均衡選択をせず、選択条件と観測シグナルを示す。
- 共通事前、完全合理性、共通知識は強い仮定であり、行動・制度データで検証する。
- 均衡は予測時刻を与えない。期限はカレンダー、セッション、学習速度、ポジション制約から別に置く。
- 市場参加者を一人の合理的主体へ集約しない。異質な期間・制約・目的を残す。
