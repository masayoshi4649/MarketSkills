# 開発経済学

## 1. 本スキルでの目的と適用条件

この教材は、新興国の成長、生産性、制度、人的資本、資源配分を、日本企業の海外需要・供給網・資源価格を介して日経225・TOPIX・NT倍率の条件付きシナリオへ接続するための基礎を定める。次を満たす場合に用いる。

- 国別売上、生産拠点、調達先、通貨、業種を区別できる。
- GDP総額、1人当たりGDP、実質成長、名目成長、購買力平価を混同しない。
- 速報性の高い市場指標と、年次の構造データを別の時間軸で扱う。
- 制度、人口、教育、生産性を単一スコアに潰さず、出所と測定誤差を示せる。

開発経済の構造変数は主に中長期の事前分布に使う。D1～D5へ入れるのは、政策決定、資本規制、災害、信用イベントなど発生時刻が明確で、企業利益への経路を確認できる場合に限る。

## 2. 体系的な基礎概念

### 2.1 成長と水準

- 生産要素の蓄積と全要素生産性を分ける。
- 高成長率は低い初期水準からの収束、人口増、資本深化、技術進歩のいずれでも起こり得る。
- 国全体の成長と日本企業が獲得できる付加価値は同じではない。

### 2.2 貧困、分配、人的資本

平均所得だけでなく分布、教育、健康、金融アクセス、労働参加を確認する。人的資本の代理変数は質を完全には測らず、内生性を持つ。

### 2.3 制度と市場

財産権、契約執行、政治制約、行政能力、金融発展は投資と生産性に関係する。ただし制度指標と所得は相互に影響し、歴史的識別結果を短期市場へ直接移せない。

### 2.4 構造転換と都市化

農業から製造業・サービスへの労働移動は集計生産性を変える。インフラ、都市集積、女性就業、教育、貿易統合により速度が異なる。製造業比率の低下を直ちに停滞と解釈しない。

### 2.5 資源配分と企業異質性

資本・労働の限界生産物の分散は、税、金融制約、規制、市場支配力、測定誤差を含み得る。再配分による反実仮想TFPはモデル依存である。

### 2.6 外部ショック

商品価格、ドル資金調達、国際金利、資本流出、感染症、気候災害は、債務構成、外貨準備、輸入依存、制度能力により影響が異なる。

## 3. 主要モデル・式・仮定

### 3.1 ソロー・モデル

`Y_t = K_t^α(A_tL_t)^{1-α}`

効率労働1単位当たり資本 `k` の動学は、

`k̇ = s f(k) - (n+g+δ)k`

コブ＝ダグラス型なら定常状態は、

`k* = {s/(n+g+δ)}^{1/(1-α)}`

一定貯蓄率、外生技術進歩、規模に関する収穫一定などが主要仮定である。短期景気や金融危機を表すモデルではない。

### 3.2 成長会計

`Δln Y = αΔln K + (1-α)Δln L + Δln A`

`Δln A` は残差であり、純粋な技術だけでなく稼働率、測定誤差、資源配分を含む。因果効果と呼ばない。

### 3.3 人的資本を含む生産関数

`Y = K^α H^β (AL)^{1-α-β}`

`H` の構築法と教育の質、健康、経験を明示する。就学年数だけを人的資本の完全尺度としない。

### 3.4 収束回帰

`g_{i,0:T} = a - b ln(y_{i,0}) + γ'X_i + ε_i`

`b>0` は条件付き収束の候補である。標本選択、初期値の測定誤差、国固定効果、構造差に注意する。

### 3.5 内生的成長の最小表現

`Y_t = A_t K_t` または知識蓄積を含む `Ȧ/A = φ(R&D, H, spillovers)` とする。知識の非競合性、外部性、規模効果の仮定が結果を左右する。

### 3.6 資源誤配分

企業 `i` の生産を `Y_i = A_iK_i^αL_i^{1-α}` とし、摩擦がなければ同一産業内で資本・労働の収益率が近づく。観測された限界生産物の分散から反実仮想TFPを計算する場合、需要マークアップ、企業固定費、データ誤差を摩擦と誤認しない。

### 3.7 国別エクスポージャー

日本企業または指数の海外需要を、

`exposure_t = Σ_c w_c × shock_{c,t}`

と集計する。`w_c` は売上、営業利益、付加価値、調達のどれかを目的別に固定する。国別GDP比率を企業売上比率の代用にしない。

## 4. 日経225・TOPIX・NT分析への条件付き接続

### 4.1 構造情報から利益へ

1. 成長ショックを消費、設備投資、建設、輸出、商品、金融へ分解する。
2. 日本企業の国別・事業別売上、現地生産、調達、通貨ヘッジへ結ぶ。
3. 制度・信用・資本規制が送金、評価倍率、資金調達へ与える影響を別にする。
4. 指数ウェイトで集計し、先物・板の需給証拠と照合する。

### 4.2 日経225とTOPIX

- 日経225では、海外成長に感応する高寄与の製造業・技術関連の個別寄与を確認する。
- TOPIXでは、商社、銀行、素材、海運、機械、内需を含む広い波及と相殺を確認する。
- 新興国の成長加速でも、現地競争、円高、商品コスト、資本規制により日本企業の利益が増えない場合がある。

### 4.3 NT倍率

開発・新興国ショックの指数別エクスポージャー差を作り、共通市場・為替・商品ベータを除いた残差を評価する。構造データが年次で、当日フローが確認できない場合はNT方向の主要根拠にしない。

### 4.4 時間軸

- D1～D5：発表時刻の明確な信用、規制、選挙結果、災害、政策イベントに限定する。
- 数か月：輸出受注、PMI、貿易、企業ガイダンスで需要経路を確認する。
- 数年：生産性、人口、人的資本、制度、インフラを評価する。

短期と長期で同じ係数を使わず、期限ごとに証拠の鮮度と伝達ラグを記録する。

## 5. 反証・限界

- 外挿の危険：国、時代、制度の異なる成長回帰係数は移植できない。
- 因果識別：制度、教育、成長の相互因果と欠落変数が大きい。
- データ品質：非公式部門、物価、人口、企業退出の測定誤差がある。
- 集計の罠：GDP成長と上場企業利益、現地需要と日本からの輸出は一致しない。
- 生存者バイアス：成功国、現存企業、利用可能データだけでモデルを選ばない。
- 政治・テールリスク：連続的な成長モデルは資本規制、紛争、債務不履行を捉えにくい。
- 時間軸不適合：年次構造指標はD1～D5の変動時刻を識別しにくい。

反証には、企業開示上の対象国売上不足、現地生産による輸出経路の遮断、商品価格・為替の逆方向、速報後の大幅改定、構造変化後のベータ不安定を含める。反証された長期物語を短期需給で正当化しない。

## 6. 現行`economic_toolkit`と将来候補

| 計算名 | 主な入力 | 返り値と監査要件 |
|---|---|---|
| `poverty_gap` | 非負所得、貧困線、任意ウェイト | 貧困率、全体平均・貧困層内平均ギャップ |
| `gini_coefficient` | 非負所得、任意ウェイト | Gini係数、加重平均、観測数 |
| `social_npv` | 便益、私的費用、外部費用、割引率 | 社会的純現在価値と内訳 |

Solow定常状態、成長会計、β収束、人的資本調整、資源配分歪み、国別リスク売上、外需露出、商品ショックは将来候補であり、現行API名ではない。購買力平価換算と市場為替換算を区別し、国コード、価格基準年、改定版、重みを残す。
