# 労働経済学

## 1. 本スキルでの目的と適用条件

雇用、失業、求人、賃金、労働時間、生産性の変化を、家計所得、企業費用、物価、金融政策、業種利益へ接続する。日経225・TOPIX・NT分析で使うのは、次の条件を満たす場合である。

- 労働力調査、一般職業紹介状況、毎月勤労統計、短観などの公式公表時刻と対象期間を確認できる。
- 市場予想、改定、季節調整、標本・ベンチマーク変更を区別できる。
- 賃金と雇用を、名目・実質、人数・時間、総額・一人当たり、正規・非正規、産業別に分解できる。
- 指数への接続は、金利・為替・物価または構成銘柄の労働費用・需要エクスポージャーで裏付ける。

労働統計は公表ラグがあり、強い雇用は需要増と費用増、金融引締め観測を同時に生み得る。固定した株価方向を割り当てない。

## 2. 体系的な基礎概念

| 概念 | 定義・区別 | 主な観測 |
|---|---|---|
| 労働力状態 | 就業者、完全失業者、非労働力人口 | 就業者数、失業率、参加率 |
| ストックとフロー | 人数の水準と、就職・離職・退出の遷移 | 求人数、求職者数、入離職 |
| 労働需給 | 企業の求人と労働者の求職 | 求人倍率、欠員、短観雇用DI |
| 賃金 | 名目、実質、所定内、所定外、賞与 | 現金給与、CPI、労働時間 |
| 生産性と労働費用 | 産出量当たりの労働投入・報酬 | 時間当たり生産性、単位労働費用 |
| 集約バイアス | 産業・雇用形態・労働時間の構成変化 | 同一労働者、産業別、総実労働時間 |
| マッチング摩擦 | 求人と求職が直ちに一致しない | 求人充足率、就職率、失業期間 |
| 人的資本・タスク | 技能、経験、技術との補完・代替 | 学歴、職種、タスク、訓練 |

失業率低下が就業増によるか、労働力退出によるかを分ける。求人倍率はハローワークの業務統計であり、全求人市場そのものではない。

## 3. 主要モデル・式・仮定

### 3.1 基本率

労働力人口を`L = E + U`とすると、

- 完全失業率: `u = U / L`
- 労働力参加率: `p = L / P_{15+}`
- 就業率: `e = E / P_{15+}`
- 有効求人倍率: `θ_A = V_A / U_A`

`V_A`と`U_A`は同じ業務統計・対象区分を使う。求人倍率とマッチングモデルの市場全体の`V/U`を同一視しない。

### 3.2 探索・マッチング

コブ＝ダグラス型のマッチングを

`M(U,V) = μ U^α V^{1-α}`

とすると、労働市場逼迫度`θ = V/U`、求職者の就職率`f(θ)=M/U=μθ^{1-α}`、求人充足率`q(θ)=M/V=μθ^{-α}`である。離職率`s`が一定なら定常失業率は、

`u* = s / (s + f)`

となる。一定規模収穫、同質的な求人・求職、安定した`μ, α, s`を仮定する。産業・地域・技能のミスマッチや求人媒体の変化があると崩れる。

### 3.3 賃金フィリップス型

期限と制度を限定した還元形として、

`Δln W_t = a + π^e_t - b(u_t-u*_t) + c z_t + ε_t`

を使える。`π^e`は期待物価、`u*`は均衡失業率、`z`は生産性、制度、交渉、輸入価格などである。`b>0`は推定対象で、国・時期・賃金定義を越えて固定しない。

### 3.4 実質賃金と単位労働費用

- 実質賃金成長率: `g_{real} = Δln W - Δln CPI`
- 単位労働費用成長率: `g_{ULC} ≈ Δln compensation_per_hour - Δln output_per_hour`

月次指数の前年比と前月比、季節調整の有無を混ぜない。賞与月や標本入替の構成効果も記録する。

### 3.5 公表サプライズと産業露出

系列`k`の公表値`x_k`、市場予想`c_k`、リアルタイム公表誤差標準偏差`σ_k`から、

`s_k = (x_k-c_k)/σ_k`

とする。指数`I`の産業別雇用・賃金露出`l_{I,j}`を使う相対露出は、

`E^{labor}_{NT} = Σ_j (l_{N225,j}-l_{TOPIX,j}) shock_j`

である。`shock_j`を全国値から産業へ配賦する場合は、推定誤差を持たせる。

## 4. 日経225・TOPIX・NT分析への条件付き接続

- 賃金上振れは、家計所得を通じた内需支援、企業マージン圧迫、サービス物価、日銀反応のどれが支配的かを確認する。
- 雇用・求人上振れは、数量増、労働供給不足、労働時間変化、生産性と組み合わせる。
- 日経225は価格加重、TOPIXは浮動株時価総額加重であり、人材サービス、小売、外食、建設、製造、金融などの露出差を実構成銘柄で測る。
- 金融政策経路を使う場合は、同時刻のJGB、OIS等の政策期待、円、銀行・高PER株の反応を確認する。
- 産業露出を明示する場合は`ΔNT_labor = Σ_k Σ_j (l_{N225,j}-l_{TOPIX,j}) β_{k,j} s_k`とし、`β_{k,j}`を産業`j`の期限一致リターン感応度とする。NTリターンへ直接推定した露出込み`β_k`を使う場合は、産業露出を再度掛けない。
- 公式公表前の求人・賃金観測はシナリオ条件、公式公表後の標準化サプライズはイベント寄与とする。実際の先物フローや板は需給へ分離する。

D1～D5では、重要な労働統計が期限内に公表される場合だけイベント分散を加える。遅行する水準データを毎日の独立ショックとして重複投入しない。

## 5. 反証・限界

- 失業率低下と参加率低下、就業者増と労働時間減を取り違えていないか。
- 名目賃金上昇を実質購買力上昇と呼んでいないか。
- 一人当たり平均の変化を同一労働者の賃上げと誤認していないか。
- 求人倍率の対象範囲、オンライン登録の制度変更、季節調整改定を確認したか。
- 公表値の速報・確報・ベンチマーク改定をリアルタイムデータで扱ったか。
- マッチング効率や均衡失業率を固定し、人口動態や技能ミスマッチを無視していないか。
- 海外研究の弾性値を日本の雇用制度へそのまま移植していないか。
- 「強い雇用は株高」「賃上げは株安」の単純則を置いていないか。

反証は、JGB・円・業種反応が想定経路と逆、賃金上振れが賞与・構成要因のみ、雇用増が低生産性・短時間層のみ、期限一致イベント感応度が統計的・経済的に消失する場合とする。

## 6. 現行economic_toolkitの計算名

| 計算名 | 最小入力 | 返り値 |
|---|---|---|
| `gini_coefficient` | 非負の賃金・所得分布、任意の重み | ジニ係数、加重平均、観測数 |
| `mincer_earnings` | 推定済み切片・係数、就学年数、経験年数 | 条件付き対数賃金、賃金指数、各項寄与 |

`mincer_earnings`は係数を推定せず、外部で識別・推定した係数から条件付き値を計算するだけである。労働力率、マッチング、実質賃金、ULC、イベント感応度は取得系列の定義や推定を伴うため、現行`economic_toolkit`の計算名ではない。
