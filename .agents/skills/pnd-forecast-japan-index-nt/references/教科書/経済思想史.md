# 経済思想史

## 1. 本スキルでの目的と適用条件

経済思想史は、分析者が無意識に置いた市場観・価値観・制度観を明示し、同じ政策や価格変化を異なる理論枠で反証するために使う。思想家の名称を売買シグナル、政治的ラベル、権威付けに使わない。

- 適用する: 「市場は直ちに均衡する」「政府支出は常に有効」「価格は全情報を反映する」等の暗黙仮定を監査するとき。
- 適用しない: 歴史的命題を現代日本の1週間リターンへ直接変換するとき。
- 原典の成立時代、制度、貨幣体制、データ制約と、現代市場への翻訳規則を分ける。

## 2. 体系的な基礎概念

- 古典派: 分業、価値、分配、蓄積、地代、利潤、国際分業を生産・階級構造から考える。
- マルクス経済学: 商品、貨幣、剰余、蓄積、再生産、危機を資本関係の運動として扱う。
- 限界革命・新古典派: 主観的価値、限界代替、希少性、均衡、最適化を形式化する。
- Keynes: 不確実性、有効需要、流動性選好、期待により不完全雇用均衡が持続し得ると考える。
- オーストリア学派・Hayek: 分散した知識、価格発見、制度の自生的秩序を重視する。
- 制度派: 法、慣習、企業、権力、技術変化が選択集合と分配を形成するとみる。
- monetarist・新古典派マクロ: 予想、政策ルール、長期貨幣中立性、裁量政策の限界を重視する。
- 情報・行動・実証的資産価格論: 情報取得費用、限定合理性、裁定制約、検証可能性を導入する。

これらは相互排他的な信条一覧ではなく、何を外生・内生・観測可能とするかが異なる研究計画である。

## 3. 主要モデル・式・仮定

思想史そのものを単一式へ還元しない。比較用に次の分析骨格だけを使う。

```text
古典派の分配恒等式（概念）:
産出 = 賃金 + 利潤 + 地代

Keynes型の有効需要（簡約）:
Y = C(Y - T) + I(r, expectations) + G + NX

貨幣数量式（恒等式）:
M × V = P × Y

期待を含む政策評価:
outcome_t = f(policy_rule, expectations_t, institutions_t, shocks_t)
```

恒等式は因果モデルではない。歴史的著作を現代のDSGE、VAR、因子モデルと同一視せず、追加仮定を明記する。

## 4. 日経225・TOPIX・NT分析への条件付き接続

| 視角 | 問い | 条件付き接続 |
|---|---|---|
| 古典派・分配 | 原材料、賃金、利潤、地代の取り分がどう変わるか | 原油・賃金・為替の業種利益差を指数ウェイトへ接続する |
| Keynes・有効需要 | 需要不足か供給制約か、政策は追加需要か代替か | 財政・金融材料を景気余力、期待、金利、為替と同時に評価する |
| Hayek・知識 | 価格が集約する情報と、板に未反映の分散情報は何か | ライブ板と遅行統計を分け、中央集権的な一点予測の限界を示す |
| monetarist・期待 | 政策の水準かルール変更か、期待が内生的に変わるか | 金利・為替・株の反応関数をレジーム別に検証する |
| 情報効率・行動 | 情報取得費用、過少反応、裁定制約のどれが観測に合うか | 価格パターンだけで決めず、ニュース、フロー、コストで競合仮説を比較する |
| 制度派 | 法、会計、指数ルール、企業統治が制約をどう変えるか | JPX制度、税制、リバランス、資本政策の具体的発効時点を使う |

NT分析では、日経とTOPIXの構成差がどの分配・需要・知識・制度経路へ曝されるかを比較する。思想ラベルからNT方向を生成しない。

## 5. 反証・限界

- 後世の通称を原著者の全主張と同一視しない。原典の版・章・時代背景を確認する。
- 規範命題と実証命題、短期安定化と長期成長、集計恒等式と因果を分ける。
- 一つの学派だけで同じデータを説明できても識別にはならない。競合仮説が異なる予測をする観測を探す。
- 歴史的制度下の貨幣・労働・企業・国際資本移動を現代日本へ無変換で適用しない。
- 思想史は確率、中心値、売買枚数の校正根拠ではない。

## 6. `economic_toolkit`への非適用

思想史は機械的な価格計算へ適用せず、現行`economic_toolkit`に専用APIはない。主体、情報、制度、調整速度、規範基準を文章の仮定台帳で比較し、恒等式と因果、原典の時代制度と現代市場を区別する。競合学説の出力を方向スコアや確率へ自動変換しない。
