# 国際経済学

## 1. 本スキルでの目的と適用条件

この教材は、為替、金利差、国際資本移動、交易条件、海外需要を、日経225・TOPIX・NT倍率の条件付き材料へ変換するための基礎を定める。次を満たす場合に用いる。

- 為替の通貨方向、スポット・フォワード、金利期間、観測時刻を統一している。
- 名目為替だけでなく、輸出入価格、契約通貨、為替ヘッジ、海外売上構成を確認できる。
- 海外指標は現地発表時刻、市場予想、改定、休日差を保持している。
- 資本フロー、貿易フロー、ディーラーのリスク負担を別の経路として扱える。

「円安なら日本株高」のような固定方向則は禁止する。原因、織込み、コスト構造、業種構成、政策反応、ポジションを条件にする。

## 2. 体系的な基礎概念

### 2.1 国際収支

経常収支、金融収支、資本移転等収支、誤差脱漏は会計上対応するが、恒等式だけで為替の因果方向は決まらない。フローの公表頻度と市場の高頻度価格を混同しない。

### 2.2 為替相場

- 名目相場は通貨方向を必ず明記する。たとえば円/ドルとドル/円では上昇の意味が逆になる。
- 実質為替は価格差を調整し、実効為替は貿易相手などの重みで集計する。
- 購買力平価は長期の基準候補であり、短期の売買水準ではない。

### 2.3 金利平価

カバー付き金利平価は、同一通貨に換算した安全資産収益の裁定関係である。無カバー金利平価は期待値を含み、時間変動するリスクプレミアムにより実証的に外れ得る。

### 2.4 為替パススルーと契約通貨

為替変動が輸出入価格、企業利益、消費者物価へ移る度合いは、契約通貨、価格設定力、ヘッジ、在庫、競争、時間軸で異なる。海外売上比率だけでは利益感応度にならない。

### 2.5 開放経済政策と国際金融循環

- マンデル＝フレミング型の含意は、為替制度、資本移動、価格硬直性、政策反応に依存する。
- 世界的なリスク選好と仲介者のバランスシートは、金利差だけでは説明できない資本移動と為替変動を生む。
- 海外需要ショックと海外金融ショックを分離する。

## 3. 主要モデル・式・仮定

### 3.1 購買力平価と実質為替

自国通貨建て外貨価格を `S_t` とすると、実質為替を

`q_t = S_t P*_t / P_t`

と定義できる。対数差では `Δln q ≈ Δln S + π* - π`。財の同質性、輸送費、非貿易財、税、価格硬直性が乖離要因である。

### 3.2 カバー付き金利平価

期間と複利規約をそろえた単純形は、

`F_t/S_t = (1+i_t)/(1+i*_t)`

である。実務のベーシスは通貨スワップ、担保、信用、規制、資金調達制約を含むため、ゼロでないこと自体を裁定機会と断定しない。

### 3.3 無カバー金利平価

`E_t[Δs_{t+1}] = i_t - i*_t + ρ_t`

`ρ_t` は通貨リスクプレミアム等を表す。期待為替は観測不能であり、実現値を代用すると予測誤差とリスクプレミアムが混ざる。

### 3.4 交易条件

`ToT_t = P^X_t / P^M_t`

輸出価格と輸入価格の相対比である。原油高でも、産油関連の利益、輸入コスト、需要ショック、為替が同時に変わるため指数効果は一意でない。

### 3.5 為替パススルー

局所的な推計式の例は、

`Δln P^M_t = α + βΔln S_t + γ'X_t + ε_t`

`β` は期間、品目、契約通貨、マージン調整に依存する。構造変化と内生性を点検し、銘柄別利益へ直接転記しない。

### 3.6 小国開放経済の縮約形

`IS: Y = C(Y-T) + I(i) + G + NX(Y,Y*,S)`

`LM: M/P = L(i,Y)`

資本移動が高い単純モデルでは国内金利と世界金利が結び付くが、リスクプレミアム、為替介入、非伝統政策、金融仲介制約を追加すると結果は変わる。シナリオは連立方程式の係数と制度を明示して解く。

### 3.7 貿易加重海外需要

`g_ext,t = Σ_c w_c g_{c,t}`、`Σ_c w_c = 1`

重み `w_c` は輸出額、海外売上、付加価値のいずれかを目的に合わせて選ぶ。総輸出額と企業の最終需要国を混同しない。

## 4. 日経225・TOPIX・NT分析への条件付き接続

### 4.1 為替ショックの分解

1. 円変動を日米金利差、純粋な政策、成長差、リスク回避、資金調達ベーシス、介入観測に仮分類する。
2. 金利曲線、株式先物、オプション、商品、クレジットの同時反応で分類を検証する。
3. 契約通貨、ヘッジ比率、輸入比率、海外利益を用いて業種別利益感応度へ写像する。
4. 指数ウェイトで集計し、需給証拠とは別に保持する。

### 4.2 日経225とTOPIX

- 日経225では高寄与銘柄の海外売上とデュレーションが全体の為替感応度を左右し得る。
- TOPIXは業種の広がりがあるため、輸出企業だけでなく銀行、内需、資源、公益の金利・交易条件感応度を含める。
- 円安が輸出換算益を増やす場合でも、輸入コスト、実質所得低下、政策引締め期待が相殺し得る。

### 4.3 NT倍率

指数別の推定為替ベータ `β_N,FX` と `β_T,FX` の差はNTの候補説明変数になる。ただし、

`Δln(NT) ≈ (β_N,FX - β_T,FX)ΔFX + 残差`

は局所近似である。ローリング窓、同時金利変化、業種寄与、先物フローを照合し、係数の符号が安定しない場合は相対推奨を保留する。

### 4.4 海外市場

米国、欧州、アジアの指数先物は「海外需要」と「世界的な割引率・リスク選好」を分けて読む。日本休場中の累積変化は、円、ADR、日経先物夜間、国債、商品と同一時刻でそろえ、重複寄与を避ける。

## 5. 反証・限界

- 為替予測の難しさ：構造モデルが短期のランダムウォーク基準を安定して上回るとは限らない。
- フォワード・プレミアム・パズル：無カバー金利平価の単純な実証含意は外れ得る。
- 内生性：為替、金利、株価、政策期待は同時に決まる。
- パススルーの異質性：企業、品目、契約通貨、局面で係数が違う。
- 集計誤差：貿易統計の相手国と最終需要国、売上国と利益通貨は一致しない。
- データラグ：国際収支と貿易統計は短期板情報より遅い。
- 仲介制約：危機時はディーラーのリスク許容度が基本モデルを上書きし得る。

反証には、想定した通貨方向と業種寄与の不一致、金利平価の期間不整合、契約通貨データの欠落、ベータの符号転換、海外市場間の時刻ずれを含める。反証時は固定符号を維持せず、確率を再配分する。

| `covered_interest_parity` | スポット、両通貨金利、期間、任意の観測フォワード | 理論フォワード、ポイント、観測乖離 |

UIP、REER、交易条件、為替転嫁、Mundell–Fleming、外需加重、世界金融循環は将来候補であり、現行API名ではない。通貨ペアの分子・分母、JST対象時刻、価格種別、金利の単利規約を明示する。
