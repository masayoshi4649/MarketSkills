# 行動経済学

## 1. 本スキルでの目的と適用条件

行動経済学は、期待形成、参照点、損失回避、注意、過少・過剰反応が価格形成へ影響する仮説を、観測可能な市場反応として検証するために使う。心理ラベルを値動きの事後説明に使わず、事前定義した参照点、ニュース、フロー、期間、反証を持つ場合だけ採用する。

- 適用する: 材料発表前後、急落・急騰後、損益分岐・大口行使価格周辺、継続フローと反転を検証するとき。
- 適用しない: 「投資家心理が悪い」だけで方向点を付けるとき、単一アンケートやSNS指標を市場全体の信念とみなすとき。
- 行動仮説はファンダメンタル価値、裁定制約、制度的フローと競合させる。

## 2. 体系的な基礎概念

- 参照点依存: 絶対富ではなく取得価格、直近高安、予想値等からの変化が効用へ影響し得る。
- 損失回避・感応度逓減: 同額の損失と利得が非対称で、参照点から離れるほど限界感応度が下がり得る。
- 確率加重: 客観確率と意思決定上の重みを分ける。
- 代表性・保守性: 小標本の傾向を外挿する過剰反応と、新情報への更新不足を区別する。
- 限定注意・顕著性: 同じ情報でも公表時刻、見出し、指数寄与度、取引時間で反応が変わり得る。
- 群集・フィードバック: 他者行動を情報とみなす合理的学習と、非合理な追随を区別する。
- 裁定の限界: ファンダメンタルからの乖離があっても資本、期間、空売り、代理人問題で直ちに解消しないことがある。

## 3. 主要モデル・式・仮定

```text
価値関数:
v(x) = x^α                         (x >= 0)
v(x) = -λ(-x)^β                    (x < 0), λ > 1

Prelec型確率加重の一例:
w(p) = exp{-η[-ln(p)]^γ}

Bayes更新差:
update_gap = logit(posterior_observed) - logit(posterior_benchmark)

イベント反応残差:
abnormal_return_t = observed_return_t - benchmark_return_t
```

パラメータは普遍定数ではない。参照点、選択課題、主体、期間で変わる。市場価格へ接続するには、限界投資家、裁定資本、取引コスト、情報到着過程の仮定が追加で必要である。

## 4. 日経225・TOPIX・NT分析への条件付き接続

| 仮説 | 必要な観測 | 条件付き接続 |
|---|---|---|
| 新情報への過少反応 | サプライズ符号、発表直後反応、以後の同方向ドリフト、出来高 | 日経寄与上位だけかTOPIX全体へ広がるかで単純方向とNTを分ける |
| 過剰反応・反転 | ベンチマーク調整済み急変、ファンダ改定幅、流動性、反転開始 | 急落だけで逆張りせず、価格反転と売り圧力減衰を確認する |
| 損失回避・処分効果 | 取得価格分布の代理、信用残、出来高集中、税・決算期 | 節目での供給増減候補とし、板・約定で検証する |
| 群集・注意 | ニュース集中、検索・フロー、寄与度集中、業種広がり | 値がさ集中ならNTロング候補、広範化なら反証となり得る |
| 裁定制約 | 空売り費用、証拠金、スプレッド、資金流出、ボラ | 相対価値の収束期限を短く断定せず、コスト帯を広げる |

行動材料は原則として需給証拠へ置く。利益予想や割引率の変更を伴う部分だけをファンダメンタルズへ置き、同じイベントを重複加点しない。

## 5. 反証・限界

- 同じ価格パターンはリスクプレミアム、税、流動性、マイクロストラクチャでも生じる。
- 参照点を価格観測後に選ぶと反証不能になる。分析前に定義する。
- 長期の反転研究をD1～D5へそのまま移植しない。対象期間一致の検証が必要である。
- センチメント指標の上昇は買い需要と過熱の双方に整合するため、方向符号を固定しない。
- 生存者バイアス、データスヌーピング、発表後改定、取引費用を含むウォークフォワードで再検証する。

## 6. 現行`economic_toolkit`と将来候補

- `prospect_value`: 参照点、α、β、λを明示して価値関数を計算する。

確率加重、Bayes更新差、イベント超過収益、過少・過剰反応、参照点感度、センチメント半減期は将来候補であり、現行API名ではない。`prospect_value`を市場確率または期待収益へ変換しない。
