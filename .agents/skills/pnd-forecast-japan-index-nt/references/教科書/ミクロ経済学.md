# ミクロ経済学

## 1. 本スキルでの目的と適用条件

ミクロ経済学は、価格変化を「選好・技術・所得・代替可能性・情報・市場構造」のどの変化が生んだかへ分解するために使う。日経225、TOPIX、NT倍率の方向を理論だけで決めず、企業利益、投入価格、需要、指数構成、板、出来高等の観測値へ接続できる場合だけ採用する。

- 適用する: 税・補助金、原油・為替、賃金、規制、価格転嫁、競争環境、情報非対称が業種利益へ伝わる場合。
- 適用しない: 集計指数の短期方向を需要供給図だけで断定する場合、代表的企業を指数全体と同一視する場合。
- 時間軸を分ける: 板の需給、決算までの利益改定、設備・参入退出の長期調整は同じ弾力性を使わない。

## 2. 体系的な基礎概念

- 機会費用と限界分析: 意思決定は総額ではなく追加1単位の便益・費用で比較する。
- 需要・供給と均衡: 均衡価格は外生定数ではなく、需要・供給関数と制度制約の交点である。
- 弾力性: 価格、所得、交差価格への数量反応を無次元化する。短期と長期、企業と市場を区別する。
- 消費者選択: 予算制約下の効用最大化。価格効果は代替効果と所得効果へ分ける。
- 企業行動: 利潤最大化、限界費用、規模の経済、固定費、操業停止・退出を分ける。
- 市場構造: 完全競争、独占、寡占、差別化、参入障壁では価格決定力と余剰配分が異なる。
- 厚生と情報: 消費者余剰・生産者余剰、外部性、逆選択、モラルハザード、情報取得費用を扱う。

## 3. 主要モデル・式・仮定

```text
需要弾力性: εQ,P = (dQ/dP) × (P/Q)
交差弾力性: εi,j = (dQi/dPj) × (Pj/Qi)
利潤: π(q) = p(q)q - C(q)
内点解の一階条件: MR(q*) = MC(q*)
Lerner指数: L = (P - MC) / P = -1/εD       （単純独占・通常の符号規約）
市場清算残差: z(p) = Σi xi(p) - Σj yj(p)
Slutsky分解: ∂x/∂p = ∂h/∂p - x(∂x/∂m)
```

式は、他条件一定、同一財・同一期間、内点解、測定可能な価格・数量などの仮定に依存する。均衡の存在は均衡への高速収束や一意性を意味しない。推定弾力性は対象期間・レジーム外へ外挿しない。

## 4. 日経225・TOPIX・NT分析への条件付き接続

| 観測 | 接続手順 | 条件付き含意 |
|---|---|---|
| 円安・原油高 | 売上通貨、投入通貨、ヘッジ、価格転嫁率、数量弾力性を企業・業種別に確認 | 値がさ輸出株と内需・運輸等の利益差を通じNTへ作用し得る |
| 金利・信用条件 | 借入比率、預貸利ざや、デュレーション、需要の金利弾力性を確認 | 銀行比重や高PER比重の差へ作用し得るが符号は固定しない |
| 税・補助金・規制 | 法的対象、負担帰着、需要供給弾力性、実施時期を確認 | TOPIXの業種広がりか日経寄与上位集中かを別々に評価する |
| 市場集中・価格決定力 | シェア、代替品、限界費用、契約更改時期を確認 | 利益率ショックの持続性を評価し、指数ウェイトで集計する |
| 板スプレッド | 情報非対称、在庫費用、呼値、流動性を分ける | スプレッド拡大を弱気方向とせず、コストと情報品質へ反映する |

集計は原則として `企業感応度 × 指数ウェイト × 実現時期 × 未織込率` とし、同じショックをファンダメンタルズと需給へ二重加点しない。

## 5. 反証・限界

- 弾力性や限界費用が未推定なら、方向仮説に留め中心ドリフトへ機械変換しない。
- 会計利益、キャッシュフロー、先物価格は異なる対象であり、短期の板を長期均衡と呼ばない。
- 代表的主体、完全情報、価格受容、合理性、摩擦なし等の仮定が崩れると比較静学の符号も変わり得る。
- 規制・税制は期待形成と移行措置を伴う。公表時、施行時、業績反映時を分ける。
- 高集中度は価格決定力の十分条件ではない。輸入競争、潜在参入、買い手交渉力で反証する。

## 6. 現行`economic_toolkit`と将来候補

- `arc_elasticity`: 2点間の価格・数量から中点法弾力性を計算する。
- `tax_incidence`: 需要・供給弾力性から単純部分均衡の税負担比率を返す。

Slutsky分解、超過需要、余剰積分、Lerner指数、指数ウェイト集計は将来候補であり、現行API名ではない。入力単位、対象期間、仮定を示し、弾力性や限界費用を推測で補わない。
