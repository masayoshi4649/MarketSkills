# 経済学教科書の索引と段階読込

## 1. 目的

この索引は、日経225・TOPIX・NT分析に必要な経済学だけを選ぶためのルーターである。毎回14冊を全読込してはならない。まず本索引を読み、観測した材料の伝達経路に直接関係する1～4冊だけを完全に読む。追加の本は、結論、4象限、D1～D5、または反証条件を変え得る場合に限って読む。

教科書は現在データの代用品ではない。モデルが示すのは条件付きの経路であり、日経・TOPIXへの符号は為替感応度、指数ウェイト、景気局面、金融政策反応、織込み、需給によって変わる。固定方向則を作らず、現在の一次資料と市場データで符号を確定する。

## 2. 読込手順

1. 現在板、経済カレンダー、ニュース、市場横断データから主要な伝達経路を3件以内に絞る。
2. 下表から直接対応する教科書を選ぶ。通常は1～2冊、複合ショックでも4冊を上限とする。
3. 選んだファイルの「適用条件」「式と仮定」「指数への接続」「反証・限界」を完全に読む。
4. 回答の予測理由に、使った教科書名、概念、現在データ、反証を対応付ける。
5. 関係しない分野は読まず、単なる知識量で証拠数を水増ししない。

## 4. 指数・NT分析の横断テーマ

指数・NT分析で頻出する横断テーマは、次の参照先から必要な分野だけを選ぶ。

| テーマ | 参照先 |
|---|---|
| 景気、物価、金融政策、金利 | [マクロ経済学.md](マクロ経済学.md)、[金融経済学.md](金融経済学.md) |
| 為替、海外市場、商品、国際波及 | [国際経済学.md](国際経済学.md) |
| 政策、税、規制、地政学シナリオ | [公共経済学.md](公共経済学.md)、[ゲーム理論.md](ゲーム理論.md) |
| 板、ベーシス、出来高、建玉、OP、SQ、ロール | [金融経済学.md](金融経済学.md) |
| 群集、過熱、反転、織込み | [行動経済学.md](行動経済学.md)、[金融経済学.md](金融経済学.md) |
| 価格転嫁、企業利益、産業構造 | [ミクロ経済学.md](ミクロ経済学.md) |

需給の直接的な板・建玉・オプション分析では、他分野を広く読む前に金融経済学を優先する。相対優位は逆符号象限を意味しないため、4象限の終端符号とNT相対収益を分ける。

## 5. 純計算ツールとの対応

[../../scripts/economic_toolkit.py](../../scripts/economic_toolkit.py)は取得済み数値だけを扱う純計算器である。計算式を使う前に対応教科書の仮定を確認し、入力時点と単位を回答へ残す。歴史・制度・因果識別を機械計算で置き換えない。

| 計算名 | 主な教科書 | 用途 |
|---|---|---|
| `arc_elasticity` | ミクロ経済学 | 価格・数量の中点弾力性 |
| `tax_incidence` | ミクロ経済学、公共経済学 | 需要・供給弾力性からの税負担分担 |
| `fisher_real_rate` | マクロ経済学、金融経済学 | 名目金利と期待物価からの実質金利 |
| `taylor_rule_gap` | マクロ経済学 | 政策金利ルール値と現行値の差 |
| `prospect_value` | 行動経済学 | 参照点依存の価値関数。市場確率ではない |
| `gini_coefficient` | 社会経済学、労働経済学、開発経済学 | 非負値分布の格差要約 |
| `mixed_nash_2x2` | ゲーム理論 | 非退化2×2ゲームの混合均衡候補 |
| `present_value` | 金融経済学、教育経済学、医療経済学 | 時系列キャッシュフローの現在価値 |
| `covered_interest_parity` | 国際経済学 | 金利差と直先為替の無裁定関係 |
| `mincer_earnings` | 労働経済学、教育経済学 | 学歴・経験と対数賃金の条件付き予測 |
| `social_npv` | 公共経済学、環境経済学、開発経済学 | 外部費用を含む社会的現在価値 |
| `poverty_gap` | 開発経済学 | 貧困線からの平均不足率 |
| `incremental_cost_effectiveness` | 医療経済学 | 増分費用効果比。閾値判断は別途行う |

## 6. 共通の監査原則

- 相関、理論上の比較静学、因果効果を区別する。
- 原著の仮定と現在市場の制度・期間が一致しない場合は適用しない。
- 現在の証拠にない符号を教科書だけから4象限へ加点しない。
- 同じ事実を複数教科書の言葉で言い換えて二重計上しない。
- 推定値には対象時点、標本、単位、信頼区間または感度分析を付ける。
- 数学的に計算できても、データ鮮度、識別、取引コスト、流動性のゲートを迂回しない。
