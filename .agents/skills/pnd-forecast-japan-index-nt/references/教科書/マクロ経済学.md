# マクロ経済学

## 1. 本スキルでの目的と適用条件

この教材は、景気・物価・金融政策・財政政策の情報を、日経225、TOPIX、NT倍率の条件付きシナリオへ変換するための基礎を定める。単一指標の水準ではなく、次をそろえた場合に用いる。

- 観測時刻、発表時刻、予測対象期間が明示されている。
- 実績値だけでなく市場予想と改定前値があり、サプライズを測れる。
- 名目金利、期待インフレ、為替、利益予想、ポジショニングを同じ基準時点で照合できる。
- 政策発表では、政策ショックと中央銀行が伝えた景気情報を分けて検討できる。

マクロ情報はファンダメンタルズの事前分布を作る。短期の方向を単独で確定せず、板、先物・オプション、裁定、フローなど需給証拠との一致を必要条件とする。

## 2. 体系的な基礎概念

### 2.1 国民所得と循環

- 支出面の恒等式は `Y = C + I + G + NX`。恒等式自体は因果モデルではない。
- 潜在産出量 `Y*` と実際の産出量 `Y` の差を需給ギャップとして扱う。
- 景気循環では、需要ショック、供給ショック、金融ショック、信用ショックを分離する。
- 先行、一致、遅行の別と、速報値の改定可能性を保持する。

### 2.2 物価、金利、期待

- 名目金利は実質金利と期待インフレに分解する。
- 株価への金利経路は、割引率、利益、金融環境、リスク選好を介する。同じ金利上昇でも原因により含意が異なる。
- 期待は市場価格、調査、モデル推計で定義が異なるため、系列を混ぜない。

### 2.3 政策と識別

- 金融政策の評価では「変更幅」より「事前予想との差」を重視する。
- 財政政策は規模、対象、財源、輸入漏出、供給制約、実施時期で乗数が変わる。
- 発表窓の金利と株価の共動を使う場合も、情報効果、同時ニュース、流動性を点検する。

### 2.4 レジーム

ゼロ金利制約、インフレ局面、デフレ局面、信用不安、完全雇用付近では係数が変わり得る。固定係数ではなく、レジーム別推計、ローリング推計、構造変化検定を併用する。

## 3. 主要モデル・式・仮定

### 3.1 フィッシャー関係

厳密形は次である。

`1 + i_t = (1 + r_t)(1 + E_t[π_{t+1}])`

低率近似は `r_t ≈ i_t - E_t[π_{t+1}]`。期待インフレの測定誤差、税、期間プレミアム、信用リスクを別途扱う。

### 3.2 需給ギャップ

`x_t = 100 × (Y_t - Y*_t) / Y*_t`

潜在産出量は観測不能であり、フィルター、産出関数、当局推計を並記する。リアルタイム推計と事後改定値を混同しない。

### 3.3 新ケインジアンの最小系

`x_t = E_t[x_{t+1}] - (1/σ){i_t - E_t[π_{t+1}] - r*_t}`

`π_t = βE_t[π_{t+1}] + κx_t + u_t`

`i_t = r̄ + π_t + φ_π(π_t - π*) + φ_x x_t + ε^i_t`

価格硬直性、合理的期待、代表的主体、線形化近傍などが主な仮定である。実務では自然利子率 `r*`、期待形成、供給ショック `u` の不確実性を入力レンジにする。

### 3.4 財政乗数

`m_G(h) = ΔY_{t+h} / ΔG_t`

これは恒常定数ではない。金融政策反応、家計の流動性制約、輸入性向、供給余力、実施ラグを条件としてシナリオ化する。

### 3.5 マクロ・サプライズ

`surprise_z = (actual - consensus) / σ_surprise`

方向が逆の指標は符号規約を明示する。`σ_surprise` は同じ指標、同じ初回公表、十分な過去窓から推計し、外れ値処理を記録する。

### 3.6 割引率感応度の一次近似

キャッシュフローを固定した局所近似として、`ΔP/P ≈ -D_E × Δk`。`D_E` は株式キャッシュフローの実効デュレーション、`k` は要求収益率である。利益期待が同時に変わる局面には単独適用しない。

## 4. 日経225・TOPIX・NT分析への条件付き接続

### 4.1 共通手順

1. 発表の実績、予想、前回値、改定、時刻を固定する。
2. ショックを成長、物価、純粋な政策、中央銀行情報、信用に仮分類する。
3. 金利曲線、円相場、海外株、商品、利益予想の同時反応で分類を反証する。
4. ファンダメンタルズ寄与と需給寄与を別々に点数化し、最後に4象限へ結合する。

### 4.2 日経225とTOPIX

- 日経225は株価平均型で寄与度が一部高値株へ集中する。割引率や成長期待の影響は構成銘柄寄与へ落として検証する。
- TOPIXは浮動株調整時価総額加重で市場の広がりを反映しやすいが、金融、輸送用機器など業種構成の影響を受ける。
- 成長サプライズが正でも、実質金利上昇や円高、コスト増を伴えば両指数の反応は一意でない。

### 4.3 NT倍率

相対仮説は `Δln(NT) = Δln(Nikkei) - Δln(TOPIX)` で表す。政策ショックを指数別の利益感応度、デュレーション、為替感応度、金融株感応度へ写像し、先物ベータと枚数調整後の残差で評価する。指数の単純な騰落差をそのままNTアルファとしない。

### 4.4 期限

経済指標の次の重要発表、政策会合、入札、SQ、主要企業決算のうち最初の再価格付け候補を期限候補とする。ただし本スキルの絶対JST期限、D5上限、最終取引セッション上限を優先する。

## 5. 反証・限界

- ルーカス批判：政策規則が変われば過去の縮約係数は不変でない。
- 同時性：金利、為替、株価は共通ニュースへ同時反応するため、相関だけでは因果を識別できない。
- 情報効果：中央銀行発表は政策変更と景況判断を同時に伝える。
- 改定とリアルタイム・バイアス：GDP、需給ギャップ、季節調整値は後日改定される。
- 非線形性：ゼロ金利、危機、供給制約では局所線形モデルが崩れる。
- 集計の罠：日本全体の景気と指数構成企業の海外利益は一致しない。
- 市場織込み：良い経済指標でも予想済みなら追加情報量は小さい。

反証条件には、想定と逆の金利・為替共動、業種寄与の不一致、イベント後の板厚低下、オプション分布の逆方向シフトを含める。反証後は係数を恣意的に変えず、シナリオ確率または保留へ反映する。

## 6. 現行`economic_toolkit`と将来候補

| 計算名 | 主な入力 | 返り値と監査要件 |
|---|---|---|
| `fisher_real_rate` | 名目金利、期待インフレ | 厳密形と近似形の実質金利、期間単位 |
| `taylor_rule_gap` | 物価、目標、需給ギャップ、係数、現行金利 | ルール金利と実績差、寄与内訳 |

需給ギャップ推定、New Keynesian動学、財政乗数、マクロサプライズ、デュレーション感応度は将来候補であり、現行API名ではない。入力時刻、系列ID、単位、改定区分、推計窓を別途監査する。
