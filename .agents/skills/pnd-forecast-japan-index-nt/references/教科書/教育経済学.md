# 教育経済学

## 1. 本スキルでの目的と適用条件

教育投資、技能形成、資格シグナル、教育機会、技術との補完性が、賃金、生産性、労働供給、財政、企業の人材制約へ伝わる経路を整理する。日経225・TOPIX・NT分析では、次の場合に限って材料化する。

- 文部科学省等の一次統計、法令・予算、企業開示から、対象人口、支出、施行時期、成果指標を確認できる。
- 学校数、在学者、進学率、学力、教育費、訓練、技能需要を別系列として扱える。
- 教育量、教育の質、能力選択、資格シグナル、家庭・地域環境を区別できる。
- 短期の制度・予算イベントと、人的資本の長期蓄積を別の予測期限へ置く。

教育政策や学力変化は通常、企業利益や指数へ届くまで長い。D1～D5に使うのは、予算、制度、企業受注・費用、採用・訓練計画など、期限内のキャッシュフローまたは価格経路が確認できる場合だけである。

## 2. 体系的な基礎概念

| 概念 | 要点 | 識別上の注意 |
|---|---|---|
| 人的資本 | 教育・訓練・経験が技能と生産性を形成する | 能力、家庭背景、自己選択 |
| 私的収益と社会的収益 | 賃金差と、生産性・外部性・財政効果は別 | 税、補助、失業、波及 |
| 教育量と質 | 就学年数と獲得技能は同じではない | 学力尺度、カリキュラム、比較可能性 |
| シグナリング | 教育が能力・持続力の情報を伝える | 生産性向上と資格効果を分ける |
| 動学的技能形成 | 早期技能が後の投資効果を高め得る | 自己生産性、動学的補完性 |
| 技能需給 | 技術・産業構造と技能供給が賃金差を決める | タスク、職種、移民、訓練 |
| 教育機会 | 費用、信用制約、地域、制度が進学を制約する | 限界参加者と平均参加者 |
| ピア・学校効果 | 同級生、教員、学校資源が成果へ作用する | 選抜、反射問題、測定誤差 |

進学率上昇を技能向上と同一視せず、学力、修了、専攻、就業、賃金を順に確認する。平均的収益率を政策で追加参加する限界層へ適用しない。

## 3. 主要モデル・式・仮定

### 3.1 教育投資の現在価値

教育年数・プログラム`s`について、追加所得`ΔY_t(s)`、直接費`C_t(s)`、逸失所得`F_t(s)`、割引率`r_t`なら、

`NPV(s) = Σ_t [ΔY_t(s)-C_t(s)-F_t(s)] / Π_{τ=1}^{t}(1+r_τ)`

とする。税、失業確率、修了確率、奨学金、残存価値を整合的に含める。私的NPVと、税収・外部性・公費を含む社会的NPVを分ける。

### 3.2 ミンサー型賃金式

`ln w_i = α + ρ s_i + β_1 x_i + β_2 x_i² + γ'Z_i + ε_i`

`s`は就学年数、`x`は潜在経験、`Z`は観測属性である。`ρ`は条件付き賃金差であり、能力バイアス、測定誤差、就業選択、一般均衡があるため、そのまま因果的な教育収益率とは限らない。操作変数や制度変更の推定値は、影響を受ける限界層への局所平均効果である。

### 3.3 動学的技能形成

年齢・段階`a`の技能`h_a`、投資`I_a`、環境`E_a`に対して、

`h_{a+1} = f_a(h_a, I_a, E_a)`

とする。

- 自己生産性: `∂f_a/∂h_a > 0`
- 動学的補完性: `∂²f_a/(∂h_a∂I_a) > 0`

関数形、技能次元、家庭投入、信用制約を明示する。補完性があることから、特定の時期の投資収益が常に最大だとは断定できない。

### 3.4 シグナリング

能力型`a`の労働者が教育`s`を選び、企業が観測した`s`から期待生産性`E[y|s]`を形成すると、競争的賃金は`w(s)=E[y|s]`となる。分離均衡には、高能力型と低能力型で教育費用の傾きが異なる等の単一交差条件が必要である。観測された賃金プレミアムは、人的資本とシグナルの和であり得る。

### 3.5 技能プレミアムと指数露出

技能労働`H`、その他労働`L`の相対賃金を簡略化して、

`ln(w_H/w_L) = a_t - (1/σ) ln(H/L)`

と置く。`a_t`は技能偏向需要、`σ`は代替弾力性である。技術導入で`a_t`が変わるため、技能供給増の短期と長期の効果は同じとは限らない。

指数`I`の技能不足・教育政策露出は、企業別労働費用、採用難、教育関連売上、設備投資の実測値`e_{I,k}`で集計し、相対露出を`e_{N225,k}-e_{TOPIX,k}`とする。

## 4. 日経225・TOPIX・NT分析への条件付き接続

- 教育予算は、予算枠、契約、受注、売上、利益、支払時期を段階表示する。EdTech・人材・通信・建設などへの波及を一括計上しない。
- 授業料、奨学金、無償化は、家計可処分所得、進学、財源、労働供給への経路を分ける。
- 技能不足・リスキリングは、企業の採用難、賃金、離職、生産性、研修費、ソフトウェア投資の開示と結ぶ。
- 日経225は価格加重、TOPIXは浮動株時価総額加重であるため、教育・人材・高技能集約企業の実構成比を再計算する。
- 政策・統計イベントのNT寄与は、`ΔNT_edu = Σ_k (e_{N225,k}-e_{TOPIX,k})β_k s_k`と置けるが、`β_k`は同じ期限のイベントデータで推定する。
- 学校基本調査や学力調査の年次変化は中長期の生産性・労働供給シナリオへ使い、単独でD1～D5の方向ドリフトにしない。

短期で市場材料になるのは、制度決定、予算、上場企業の受注・ガイダンス、採用・賃金への即時経路がある場合である。長期人的資本効果を現在価値へ変換するときは、実現確率、ラグ、割引率、不確実性を明示する。

## 5. 反証・限界

- 就学年数と技能、資格と生産性、平均収益と限界収益を混同していないか。
- 家庭背景、能力、地域選択、学校選抜、就業選択を因果効果と誤認していないか。
- テスト尺度、母集団、調査方式、カリキュラム変更を時系列変化として扱っていないか。
- 教育支出額を成果、企業売上、企業利益へ直接変換していないか。
- 海外の教育収益率や学校効果を、日本の制度・賃金構造へ無調整で移植していないか。
- 少子化による生徒数減と、一人当たり支出・教育需要の変化を分けたか。
- 技能偏向技術進歩と自動化による代替、新タスク創出を同時に評価したか。
- 年次の構造指標を当日・週次の株価方向へ固定接続していないか。

反証は、予算未成立・執行遅延、受注・企業ガイダンス不変、参加・修了・技能成果の不成立、賃金プレミアムの構成要因化、期限一致の指数感応度消失とする。

## 6. 現行economic_toolkitの計算名

| 計算名 | 最小入力 | 返り値 |
|---|---|---|
| `present_value` | 等間隔の追加所得－直接費－逸失所得、一定割引率、初期期間 | NPV相当の現在価値、期間別現在価値 |
| `mincer_earnings` | 推定済み切片・係数、就学年数、経験年数 | 条件付き対数賃金、賃金指数、各項寄与 |

`present_value`は一定割引率だけを扱い、IRR、修了確率、一般均衡を推定しない。`mincer_earnings`は回帰推定器ではなく、外部で識別・推定した係数から条件付き賃金を計算する。技能形成、限界教育収益、政策から企業利益・指数への橋渡しは現行`economic_toolkit`の計算名ではない。OLSの`ρ`を自動的に因果収益率と命名しない。
