# 金融経済学

## 1. 本スキルでの目的と適用条件

この教材は、価格、収益率、リスク、流動性、デリバティブ情報を、日経225・TOPIX・NT倍率の確率予測とヘッジ比率へ変換するための基礎を定める。次を満たす場合に用いる。

- 現物、先物、オプション、金利、配当の観測時刻と限月がそろっている。
- 約定値と気配値、原資産と派生商品、実世界確率とリスク中立確率を区別できる。
- 価格加重と浮動株調整時価総額加重の差を保持できる。
- 取引費用、呼値、証拠金、ロール、板厚を含む実行可能性を別に評価できる。

モデル価格は裁定関係または条件付き期待値であり、売買方向そのものではない。予測にはファンダメンタルズ、需給、モデル誤差、流動性を併記する。

## 2. 体系的な基礎概念

### 2.1 収益率と複利

- 単純収益率は `R_t = P_t/P_{t-1} - 1`。
- 対数収益率は `r_t = ln(P_t/P_{t-1})` で、期間加算できる。
- 異なる時刻、通貨、配当処理、限月の収益率を直接比較しない。

### 2.2 裁定、価格測度、リスクプレミアム

- 一物一価は同一キャッシュフロー、同一時刻、同一資金調達条件の下で成立する。
- リスク中立価格は割引後ペイオフの価格測度下期待値であり、実世界の発生確率ではない。
- 期待収益率はリスク、選好、制約、情報、需給の影響を受ける。

### 2.3 分散、共分散、分散投資

ポートフォリオ分散は個別分散だけでなく共分散に依存する。相関は危機時に変化し、ローリング窓の選択で推計値が変わる。分散最小化と損失確率最小化は同じ目的ではない。

### 2.4 市場の情報と流動性

- ビッド・アスク、板厚、価格インパクト、出来高、建玉は異なる需給面を測る。
- 約定方向推定は誤分類を含む。出来高増加を買い需要と自動解釈しない。
- 情報取引と流動性取引が混在するため、価格変化と注文フローの同時性に注意する。

### 2.5 ボラティリティ

ヒストリカル、実現、条件付き、インプライドの各ボラティリティは測度と期間が異なる。日次標準偏差を単純に `√N` 倍する近似は独立同分布を仮定する。

## 3. 主要モデル・式・仮定

### 3.1 平均・分散モデル

`min_w w'Σw`、制約 `w'μ = μ*`, `w'1 = 1`

期待収益 `μ` と共分散 `Σ` が安定し、二次効用または楕円分布を想定する。推計誤差が大きいため、縮小推定と感度分析を必要とする。

### 3.2 CAPM

`E[R_i] - R_f = β_i(E[R_m] - R_f)`

`β_i = Cov(R_i,R_m)/Var(R_m)`

単一期間、平均分散効率的市場ポートフォリオ、摩擦なし等が仮定である。指数間の短期残差をCAPMだけで説明しない。

### 3.3 最小分散ヘッジ

現物または対象ポジション `S` を先物 `F` でヘッジするとき、符号規約を固定した局所解は次である。

`h* = Cov(ΔS, ΔF) / Var(ΔF)`

枚数は契約乗数と価格を含む金額ベータへ変換する。NTでは単純倍率と統計的ヘッジ比率を別の値として示す。

### 3.4 ブラック＝ショールズ

欧州型コールについて、

`C = Se^{-qT}N(d1) - Ke^{-rT}N(d2)`

`d1 = {ln(S/K) + (r-q+σ²/2)T}/(σ√T)`、`d2 = d1 - σ√T`

連続売買、対数正規拡散、一定の金利・配当・ボラティリティ、摩擦なしが主要仮定である。実務ではスマイル、ジャンプ、離散配当、夜間ギャップを反映する。

### 3.5 オプションからの状態価格密度

同一期限のコール価格 `C(K,T)` が十分滑らかなとき、

`q_Q(K) = e^{rT} ∂²C(K,T)/∂K²`

これはリスク中立密度である。離散ストライクの補間、裁定違反、気配スプレッドにより二階微分が不安定になるため、非負性と積分値を検証する。

### 3.6 条件付き分散

GARCH(1,1) は、

`σ_t² = ω + αε_{t-1}² + βσ_{t-1}²`

通常は `ω>0`, `α,β≥0`、弱定常性には `α+β<1` を要する。ジャンプ、非対称性、レジーム転換は別モデルで検討する。

実現分散は高頻度収益から `RV_t = Σ_j r_{t,j}²` とする。マイクロストラクチャ・ノイズ、昼休み、夜間リターン、時刻ずれを補正する。

### 3.7 価格インパクト

Kyle型の縮約表現は `ΔP_t = λQ_t + ε_t`。`Q_t` は符号付き注文フロー、`λ` は価格インパクトである。線形性と安定性を仮定するため、板薄化や制限値付近では局所推計に限定する。

## 4. 日経225・TOPIX・NT分析への条件付き接続

### 4.1 日経225オプション

- 同一期限・同一時刻の気配から裁定制約付きボラティリティ曲面を作る。
- リスク中立分布の中央値、分位点、歪度は市場価格に含まれる保険料込みの指標として使う。
- D1～D5の実世界予測帯へ移すときは、過去の予測誤差または分散リスクプレミアムで校正する。

### 4.2 TOPIX

TOPIXオプションまたは先物データが疎い場合、日経のボラティリティをそのまま転記しない。TOPIX自身の実現分散、日経との動的共分散、業種寄与、配当・金利を使い、代用関係を明示する。

### 4.3 NT倍率と枚数

- 水準倍率は `NT = Nikkei_price / TOPIX_price`。
- TOPIX mini 1枚と日経225 miniの価格感応度換算は、それぞれの価格と契約乗数を使う。
- 最小分散枚数はローリング共分散から別計算し、呼値単位へ丸める前後の残差を示す。
- NTロング・ショートは、共通市場ベータを除いた相対価値、板、ロール、配当差、限月差がそろった場合だけ候補にする。

### 4.4 4象限

日経とTOPIXの条件付き収益率分布を共同分布として推計し、`(+,+)`, `(+,-)`, `(-,+)`, `(-,-)` の領域積分を行う。周辺確率を独立と仮定して掛け合わせない。校正後に合計100%とし、丸め残差の配賦規則を固定する。

## 5. 反証・限界

- モデルリスク：拡散、正規性、定常性、一定相関は危機時に崩れる。
- 測度の混同：オプションのリスク中立確率を勝率と呼ばない。
- 先読みと同期ずれ：現物引け、先物夜間、海外市場、為替の時刻をそろえる。
- 流動性バイアス：ゼロ出来高の気配や広いスプレッドは密度推計を歪める。
- 選択バイアス：最も良く見える窓や限月を事後選択しない。
- 取引費用：理論上の小さいNT残差はスプレッド、手数料、ロールで消える。
- 構成差：日経225とTOPIXの指数設計差を単純ベータで完全には除去できない。

反証には、プット・コール・パリティ違反、負の密度、校正外れ、ヘッジ残差の構造変化、板の消失、約定可能価格からの乖離を用いる。反証されたモデルは重みを下げ、都合のよい代替窓へ無記録で切り替えない。

## 6. 現行`economic_toolkit`と既存指数計算器

| 計算名 | 主な入力 | 返り値と監査要件 |
|---|---|---|
| `present_value` | キャッシュフロー、割引率、初期期間 | 現在価値と期間別寄与 |
| `fisher_real_rate` | 名目金利、期待インフレ | 厳密形と近似形の実質金利 |

4象限、二変量分布、OP変動幅、EWMA入力、NTヘッジ比率、整数枚数、板コストは別の`index_nt_calculator.py`が検証する。平均分散フロンティア、CAPM、Black–Scholes Greeks、Breeden–Litzenberger密度、GARCH、実現分散、Amihud指標、分散リスクプレミアムは現行`economic_toolkit`のAPI名ではない。
