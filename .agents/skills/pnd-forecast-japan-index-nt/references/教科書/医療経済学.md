# 医療経済学

## 1. 本スキルでの目的と適用条件

疾病・健康、保険、診療報酬、薬価、医療供給、人口高齢化を、家計、企業利益、財政、労働供給へ分解する。日経225・TOPIX・NT分析では、次の条件を満たす場合に使う。

- 厚生労働省、国立社会保障・人口問題研究所、自治体、企業開示などの一次資料で対象、施行日、価格・数量、財源を確認できる。
- 感染症、承認、薬価・診療報酬改定、保険給付変更などについて、公表前の市場予想と公表後の差を区別できる。
- 医薬品、医療機器、病院・調剤、保険、介護、雇用、財政への異なる作用を分けられる。
- 短期イベントと、高齢化・健康資本・医療費の長期傾向を同じ期限へ混ぜない。

医療支出増は、医療企業の売上、家計負担、保険料・税負担、JGB供給、健康改善による労働供給を異なる方向へ動かし得る。固定した指数方向を置かない。

## 2. 体系的な基礎概念

| 概念 | 要点 | 分析上の区別 |
|---|---|---|
| 健康と医療 | 健康は効用・生産能力の状態、医療は投入の一つ | 医療費と健康成果を同一視しない |
| 不確実性 | 疾病発生、治療効果、費用が事前に不確実 | 保険価値と情報問題を分ける |
| 情報の非対称性 | 患者、保険者、医療提供者で情報が異なる | 逆選択、モラルハザード、代理関係 |
| 保険 | 所得移転によるリスク平準化 | 給付拡大、自己負担、加入選択 |
| 需要誘発・供給制約 | 価格だけでなく紹介、設備、人員、規制が数量を決める | 医師、病床、薬剤、待機時間 |
| 技術進歩 | 新治療が費用、質、生存、代替を変える | 価格効果と数量・質効果 |
| 費用効果 | 追加費用と追加健康成果を比較する | 平均費用でなく増分を使う |
| 財政・分配 | 公費、保険料、自己負担の帰着が異なる | 国民医療費、社会保障給付、民間支出 |

「国民医療費」は保険診療の対象となり得る傷病治療費の推計であり、予防接種、正常分娩、介護などをすべて含む総健康支出ではない。統計範囲を先に固定する。

## 3. 主要モデル・式・仮定

### 3.1 健康資本

期首健康資本`H_t`、健康投資`I_t`、減耗率`δ_t`に対して、

`H_{t+1} = (1-δ_t)H_t + I_t`

とする。健康は効用を生み、健康な時間を増やし得る。`I_t`は医療だけでなく時間、予防、生活環境を含む。医療投入から健康成果への生産関数、年齢別減耗、所得・教育との内生性を別に推定する。

### 3.2 保険と自己負担

疾病確率`p`、損失`L`、保険料`π`、給付`r`、初期資産`c`なら、

`EU = (1-p)u(c-π) + p u(c-π-L+r)`

で表せる。保険は限界価格を下げて利用を増やし得るが、その増分すべてを浪費とみなさない。リスク保護、健康便益、所得効果、供給者行動を同時に評価する。

価格弾力性は`ε_p = ∂ln Q / ∂ln P_{out-of-pocket}`である。制度、所得、医療種別、短期・長期で異なるため外部研究の一点値を固定しない。

### 3.3 費用効果分析

介入1と比較対象0の費用`C`、健康成果`E`に対して、

- 増分費用効果比: `ICER = (C_1-C_0)/(E_1-E_0)`
- 正味金銭便益: `NMB(λ) = λ(E_1-E_0) - (C_1-C_0)`

`E`をQALYとする場合、効用尺度、期間、割引率、対象集団を明示する。`E_1=E_0`のときICERを計算しない。ICERは企業価値や株価収益率ではない。

### 3.4 医療費成長の分解

整合した分類で、総医療費`M`の対数変化を近似的に、

`Δln M ≈ Δln N + Δln A + Δln U + Δln P + Δln Q_m`

と分ける。

- `N`：人口
- `A`：年齢・疾病構成
- `U`：一人当たり利用量
- `P`：同質サービス価格
- `Q_m`：治療内容・品質・技術ミックス

交差項が大きい場合は指数分解を用い、残差を明示する。薬価下落と高価格新薬への構成変化を相殺して隠さない。

### 3.5 政策サプライズと指数露出

改定率、対象患者、数量、施行確率、施行時期から企業`i`の追加利益候補`ΔΠ_i`を組み立てる。持続期間、税、再投資、割引率、リスク変化を含む企業価値モデル`V_i(·)`により、株主価値の変化と企業リターンを、

`ΔV_i^{equity} = V_i(ΔΠ_i; persistence, tax, reinvestment, discount, risk)`

`r_i^{health} = ΔV_i^{equity} / V_i^{equity}`

と変換する。指数`I`の一次近似は`Impact_I = Σ_i w_{I,i} r_i^{health}`である。`w`は実日時点の日経225価格加重またはTOPIX浮動株時価総額加重とする。NT相対値は`Impact_{N225}-Impact_{TOPIX}`とし、二重上場やサプライチェーンの重複を除く。利益から株主価値への検証可能な変換がなければ、`ΔΠ_i`は利益帰属として止め、指数リターンやbpと呼ばない。

## 4. 日経225・TOPIX・NT分析への条件付き接続

- 薬価・診療報酬改定は、改定率だけでなく対象品目、数量、原価、流通、代替、施行日を企業別に橋渡しする。
- 新薬・医療機器は、試験結果、承認、保険収載、価格、生産能力、特許、対象患者数を別ゲートにする。臨床成功確率を売上確率と同一視しない。
- 感染症は、公式症例・入院、政策制約、労働欠勤、需要代替、供給網を分離する。検索量や単発報道だけで罹患率を作らない。
- 医療・介護支出の増加は、ヘルスケア利益と財政・保険料負担を同時に評価し、JGB金利、円、内需の実反応を確認する。
- 日経225とTOPIXのヘルスケア構成比、価格加重と浮動株時価総額加重の差を実構成銘柄で再計算する。
- NT寄与は、期限内イベントの標準化サプライズ、企業別利益感応度、指数相対露出が揃う場合だけbpへ変換する。

人口高齢化、慢性疾患、健康資本は中長期シナリオに使う。D1～D5へ使うのは、期限内の制度決定、公表、承認、疫学ショックなど、時点を特定できる材料に限る。

## 5. 反証・限界

- 医療費増加を数量増、価格上昇、品質改善、人口高齢化へ分けたか。
- 保険給付の拡大を医療企業の純利益増と直結させず、価格規制・数量・競争・財源を確認したか。
- QALY、ICER、NMBを株価目標や会計利益へ読み替えていないか。
- 観察データで健康状態による保険加入の選択、供給者選択、逆因果を処理したか。
- 海外の自己負担弾力性や臨床結果を、日本の皆保険・価格規制へ無調整で移植していないか。
- NDB、国民医療費、社会保障費用統計の対象範囲・公表ラグ・匿名化を確認したか。
- 疫学上の有意差と、対象企業の増分キャッシュフローを分けたか。
- 医療政策の厚生評価と株主利益の評価を混同していないか。

反証は、対象患者・数量・価格が想定を下回る、施行延期、代替治療への移行、企業ガイダンス不変、JGB・円・指数相対反応が想定経路と不整合、期限一致感応度が失敗する場合とする。

## 6. 現行economic_toolkitの計算名

| 計算名 | 最小入力 | 返り値 |
|---|---|---|
| `present_value` | 等間隔の費用・便益キャッシュフロー、一定割引率、初期期間 | 現在価値合計、期間別現在価値 |
| `incremental_cost_effectiveness` | 新規介入・比較対象の費用と効果 | 増分費用、増分効果、ICER、費用効果平面 |

`present_value`は一定割引率の純計算であり、臨床確率、制度確率、売上確率、企業価値モデルを推定しない。`incremental_cost_effectiveness`も採用閾値、予算影響、公平性を決めない。健康資本、需要弾力性、支出分解、企業利益・指数露出は現行`economic_toolkit`の計算名ではない。
