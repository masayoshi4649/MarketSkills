# 公共経済学

## 1. 本スキルでの目的と適用条件

公共経済学は、税、補助金、政府支出、規制、公共財、外部性が企業利益・家計需要・金利・期待へ伝わる経路を分解するために使う。政策見出しを株価方向へ直結させず、法的対象、財源、規模、実施時期、代替行動、負担帰着を確認できる場合だけ採用する。

- 適用する: 予算、税制改正、エネルギー・環境政策、産業補助、社会保障、公共投資、金融規制。
- 適用しない: 成立前の案を確定支出とみなす場合、予算総額を企業売上へそのまま足す場合。

## 2. 体系的な基礎概念

- 公共財: 非競合性・非排除性とフリーライドを区別する。
- 外部性: 私的限界費用・便益と社会的限界費用・便益の乖離。
- 税の帰着: 法定負担者ではなく、価格・賃金・利潤を通じた実質負担者を弾力性で考える。
- 死荷重: 税・規制が相互に有益な取引を減らす厚生損失。ただし再分配目的とは別評価する。
- 最適課税: 税収、効率、公平、情報制約、行政費用のトレードオフ。
- 費用便益分析: 追加的社会便益・費用を同じ基準時点へ割り引く。
- 財政乗数とクラウディングアウト: 景気余力、金融政策、輸入、財源、供給制約で効果が変わる。
- 政府の失敗・制度: 情報、執行能力、時間非整合、レントシーキングも政策効果を変える。

## 3. 主要モデル・式・仮定

```text
外部性を含む効率条件: SMB(q*) = SMC(q*)
Pigou税の単純形: t* = MEC(q*)

Samuelson公共財条件:
Σi MRS_i(G, X) = MRT(G, X)

税収: R(t) = t × B(t)
限界超過負担の局所近似: DWL ≈ 0.5 × |ΔP| × |ΔQ|

正味現在価値: NPV = Σt (Benefit_t - Cost_t)/(1+r_t)^t
```

部分均衡式は一般均衡、分配、資金調達、期待変化を省く。財政乗数は定数ではなく、政策手段・状態・期間に条件づく推定対象である。

## 4. 日経225・TOPIX・NT分析への条件付き接続

| 政策 | 必須確認 | 条件付き接続 |
|---|---|---|
| 補助金・公共調達 | 予算成立、対象、補助率、執行期間、国内調達条件 | 受益企業の売上寄与を指数ウェイトで集計し、競争・費用増を控除する |
| 法人・消費・関税 | 課税標準、時期、需要供給弾力性、価格転嫁 | 利益、家計需要、輸入コストを業種別に分ける |
| 環境・エネルギー | 排出価格、無償枠、電源構成、原油・電力代替 | 資源・商社・電力・製造・運輸の相反効果をTOPIXと日経で再集計する |
| 社会保障・家計移転 | 対象家計、限界消費性向、財源、恒久性 | 内需広がりと金利・財政懸念を同時に検証する |
| 金融・資本規制 | 適用金融機関、資本・流動性要件、移行期間 | 銀行比重と市場流動性へ作用し得るが、金利方向と分離する |

政策の発表効果、成立確率、執行キャッシュフロー、長期供給効果を別時点に置く。具体政策が結論を変え得る場合だけ政策DB・一次法令を確認する。

## 5. 反証・限界

- 予算枠、契約額、売上、利益、キャッシュ受領を同一視しない。
- 法定税率から実効税率や帰着を推測しない。控除、損金、国際移転、弾力性を確認する。
- 支出増と国債金利上昇、通貨、輸入漏出、民間投資抑制の競合経路を残す。
- 政策期待が既に価格へ織り込まれていれば、公表時の追加効果は小さいか逆転し得る。
- 政策採択確率は実施規模や日本株条件付きリターンではない。
- 厚生改善と上場企業利益増加は別の評価軸である。

## 6. 現行`economic_toolkit`と将来候補

- `tax_incidence`: 部分均衡の買い手・売り手負担比率を計算する。
- `present_value`: 期間別の純便益または費用を一定割引率で現在価値へ変換する。
- `social_npv`: 便益、私的費用、外部費用を分離した社会的純現在価値を計算する。

死荷重、Pigou楔、公共財条件、状態別財政乗数、政策の指数露出、予算から企業利益への橋渡しは将来候補であり、現行API名ではない。
